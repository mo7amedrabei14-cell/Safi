# Anthropic Knowledge Work Plugins — قوالب المعرفة والتقارير (SafiData)

تُستخدم هذه المهارة لتوليد المستندات المعرفية المهيكلة محليًا وبصياغة عربية رصينة (الأقسام 5، 16.4، 18.10، 20.1).

## القوالب المعتمدة داخل المشروع
1. **قاموس البيانات التلقائي (`Data Dictionary — U8 / T2.09`)**:
   - يولّد جدولاً توثيقيًا لكل عمود: الاسم، النوع المكتشف، نسبة الامتلاء، القيم المميزة، القواعد المطبقة، ومعاني الرموز، جاهزًا للتصدير بصيغة PDF عبر `Typst` أو Markdown.
2. **الملخص التنفيذي للتقارير (`Executive Summary — D11 / T3.11`)**:
   - قوالب لغوية عربية حتمية تدمج الأرقام المحسوبة من المحرك مع مصدر حساب كل رقم (`Lineage`).
3. **تقارير المنظمات والعمل الإنساني (`Humanitarian 3W/4W/5W & HXL — N1, N3, N7`)**:
   - قوالب قياسية لـ «من يفعل ماذا وأين ومتى ولمن» متوافقة مع وسوم `HXL` ورموز `P-codes` مع فحص `k-anonymity` قبل التصدير.
