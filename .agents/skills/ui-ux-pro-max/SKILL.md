# UI/UX Pro Max Skill — SafiData (صافي البيانات)

إلزامي لكل مهمة تمس الواجهة أو الرموز التصميمية أو الرسوم البيانية (الأقسام 6، 7، 17، 18.9، 20.1).

## القواعد الملزمة (Non-Negotiable Design Rules)
1. **العربية والـ RTL أولًا (`RTL-First`)**:
   - استخدام الخصائص المنطقية فقط (`ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`, `end-*`, `text-start`, `text-end`).
   - عكس أيقونات الاتجاه تلقائيًا في الوضع العربي، وعزل الأرقام والمعرّفات اللاتينية بـ `dir="ltr"` و`unicode-bidi: isolate` لمنع تداخل الاتجاهين (`bidi`).
2. **معيار الإتاحة `WCAG 2.2 AA`**:
   - نسبة التباين للنصوص العادية $\ge 4.5:1$ (اللون الخافت الفاتح المعتمد هو `#5B6B7F` على `#F5F7FA` بتباين $\approx 5.0:1$ وفق القرار `ن5`).
   - نسبة التباين لعناصر الرسوم ومكونات الواجهة $\ge 3.0:1$.
   - حجم الهدف القابل للنقر $\ge 44 \times 44\text{ px}$ مع فاصل $\ge 8\text{ px}$.
   - التركيز غير المحجوب (`Focus Not Obscured` — 2.4.11): التزام `scroll-padding-top` للشريط الثابت.
3. **بديل لكل سحب وإفلات (`Drag Alternative` — 2.5.7)**:
   - كل عنصر يقبل السحب والإفلات يجب أن يوفّر بديلًا بنقرة واحدة (أزرار «انقل لأعلى / لأسفل» أو قائمة سياقية).
4. **نظام التصميم (`Tailwind CSS v4 Design Tokens`)**:
   - يُمنع استخدام ألوان أو مسافات عشوائية خارج متغيرات CSS المعرّفة في `packages/design-tokens`.
   - دعم كامل للوضعين الفاتح (`light`) والداكن (`dark`)، وكثافتي العرض («مريح» `comfortable` و«مدمج» `compact`).
5. **الحركة المدروسة (`Motion Discipline`)**:
   - حركة رئيسية واحدة أو اثنتان في الشاشة الواحدة كحد أقصى.
   - احترام `prefers-reduced-motion: reduce` بإيقاف الحركات غير الضرورية فورًا.
