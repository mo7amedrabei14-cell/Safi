# صافي البيانات | SafiData (`safi`) — v5.0 Gold Master

منصة عربية أصيلة، تعمل محليًا أولًا (`Local-First`)، لتنظيف البيانات وفهمها ورسمها وإصدار التقارير المتجهية الفورية دون أن تغادر بيانات المستخدم جهازه.

## المبادئ المعمارية الصارمة
- **محلي أولًا وصفر شبكة في المحرك**: يعمل محرك Rust (`crates/sf-*`) بالكامل داخل جهاز المستخدم (عبر WebAssembly داخل Web Worker في المتصفح أو أصليًا عبر Tauri 2.2 وسطر الأوامر `safi`)، مع فحص آلي يمنع دخول أي مكتبة شبكة للمحرك (`tools/check-no-network.sh`).
- **عربي أصيل من الجذر**: دعم كامل لاتجاه RTL، وتوحيد الهمزات والياء والتاء المربوطة، والأرقام العربية والهندية، والتقويم الهجري والميلادي، وتوليد تقارير PDF عربية متجهية متصلة الحروف عبر محرك **Typst** المضمّن.
- **حتمية مطلقة**: نفس الملف + نفس الوصفة = نفس الناتج بايتًا ببايت، مع عدم المساس بملف المستخدم الأصلي أبدًا.

## البدء السريع وفحص البوابة الشاملة

راجع ملف [`COMMANDS.md`](./COMMANDS.md) و[`docs/COMMANDS.md`](./docs/COMMANDS.md) لجميع الأوامر. لتشغيل بوابة الفحص الكاملة:

```bash
make check
```
