# دليل التشغيل والمعاينة — منصة صافي البيانات (`SafiData v5.0`)

منصة عربية محلية أولًا لتنظيف البيانات، الرسم، وإصدار التقارير المتجهية الفورية.

## 1. المتطلبات الأساسية
- Node.js LTS (إصدار حديث مع `pnpm`)
- Rust (Cargo) للإصدارات الأصلية ومحرك WASM.

## 2. أوامر التشغيل والبناء المحلية
- **تثبيت الاعتماديات**: `pnpm install`
- **تشغيل خادم التطوير**: `pnpm --filter @safi/web dev`
- **تشغيل الاختبارات الشاملة**: `pnpm run test` أو `make check`
- **بناء التطبيق للإنتاج**: `pnpm build`

## 3. النشر التجريبي والمعاينة (Cloudflare Pages)
- التطبيق مُهَيَّأ للنشر المباشر على **Cloudflare Pages** مع ترويسات الأمان الصارمة (`_headers`) وقواعد التوجيه أحادي الصفحة (`_redirects`).
- للرفع، اربط مستودع GitHub بـ Cloudflare Pages مع إعدادات البناء التالية:
  - **Framework preset**: Vite
  - **Build command**: `pnpm build`
  - **Build output directory**: `dist` (أو المجلد الناتج للمتصفح)
