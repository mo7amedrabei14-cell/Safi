# نموذج التهديدات الأمنية (`docs/THREAT_MODEL.md` — القسمان 8 و18.4)

يوثّق هذا الملف التهديدات الأمنية الأساسية والضوابط الهندسية الإلزامية في **«صافي البيانات | SafiData» (`v5.0 Gold Master`)**.

| # | التهديد | الضابط الهندسي الإلزامي | الشريحة |
| --- | --- | --- | --- |
| 1 | تسريب بيانات المستخدم عبر المحرك | حظر أي مكتبة شبكة في `crates/sf-*` وفحص آلي صارم في `tools/check-no-network.sh` يوقف البناء فورًا. | S1 (`T1.00`) |
| 2 | قنابل الضغط (`Zip Bomb`) والملفات المتضخمة في `xlsx` | فحص نسبة الضغط وحد الحجم الأقصى قبل فك الضغط، ورفض الملف بالرمز `SF-IMP-005`، وتشغيل المحرك داخل Web Worker بحدود وقت وذاكرة. | S1 |
| 3 | حقن الصيغ (`CSV/Excel Formula Injection`) عند التصدير | تحييد أي خلية نصية تبدأ بـ `=` أو `+` أو `-` أو `@` أو `Tab` أو `CR` عند التصدير، وعدم تنفيذ أي صيغ أو ماكرو. | S1 |
| 4 | هجمات XSS وتنفيذ الكود في المتصفح أو Tauri Webview | سياسة `CSP` صارمة (بلا `unsafe-inline` ولا `unsafe-eval`)، ومنع تحميل أي موارد خارجية. | S1 / S5 |
| 5 | هجمات سلسلة التوريد (`Supply Chain`) | تثبيت الإصدارات بدقة (`save-exact=true`)، وتعطيل `postinstall` (`ignore-scripts=true`)، وفحص الاعتماديات آليًا. | S1 (`T1.00`) |
| 6 | التعبيرات النمطية المدمّرة (`ReDoS`) | استخدام محرك تعبيرات خطي الزمن فقط (`regex` في Rust) ومنع التراجع الأسي. | S1 |
| 7 | تجاوز المسارات (`Zip-Slip / Path Traversal`) | تطبيع المسارات ورفض الخروج من المجلد الهدف ومنع الروابط الرمزية (`Symlinks`). | S1 / S5 |
| 8 | حقن التعليمات عبر محتوى الخلايا (`Prompt Injection`) | الذكاء الاصطناعي يعيد مواصفة JSON فقط تُتحقق بمخطط صارم، بلا أدوات ولا تنفيذ كود، وتُرسل العينات مقنّعة كبيانات فقط بعد موافقة صريحة. | S6 |
| 9 | اختراق الخادم أو تسريب بيانات المستأجرين | عزل المستأجرين عبر سياسات `RLS` الأصلية في PostgreSQL 18، وتشفير الوصفات والكتل من الطرف للطرف (`XChaCha20-Poly1305`) بحيث لا يرى الخادم محتوى الملفات أبدًا. | S4 / S6 |
| 10 | العبث بالتحديثات أو مفاتيح التوقيع | عزل مفتاح التوقيع `Ed25519` في AWS KMS وربطه بمصادقة WebAuthn بمفتاح `YubiKey 5` المادي للمالك. | S5 |
