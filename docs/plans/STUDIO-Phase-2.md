# خطة STUDIO-Phase-2

**الحالة:** لم يبدأ؛ لا تنفيذ قبل قبول Phase 1.  
**العقد:** [المهمة](../tasks/STUDIO-Phase-2.md).

## الحدود

إعادة استخدام DataGraph/Worker/tokens من Phase 1 دون إنشاء محرك حساب آخر. لا شبكة في Rust، ولا مزود AI خارجي مفعل تلقائيًا، ولا تغييرات auth/DB/consent خارج التكليف.

## خطوات التنفيذ

1. **DSL إصـداري:** تعريف أوامر declarative مع schema/AST ومعنى واضح للصلاحية والموارد والأنواع؛ دمج validator Rust مع المعاملات الذرية في DataGraph. لا tool calls أو مسارات ملفات أو كود حر داخل نتيجة AI.
2. **تفسير فعلي:** توصيل شريط أوامر عربي/إنجليزي بقدرة AI محلية معتمدة ومتاحة فعليًا. إن لم تتوفر، يتوقف التكامل بدل تسمية parser شكلي بأنه AI. الموارد/النموذج/الترخيص تحتاج تحققًا قبل إضافة اعتماديات.
3. **حد الثقة:** نتيجة AI بيانات غير موثوقة؛ التحقق من الأعمدة والمقاييس والأنواع والمراجع والأوامر قبل أي تنفيذ. لا حقل يقبل قيمة verified من AI؛ القيم تأتي من حساب Rust وحده.
4. **Narrative:** Blocks نصية ومراجع metric مستقرة؛ فصل user/AI provenance، ودعم عناوين وقوائم وتنسيق ولغتين. unresolved/stale مرئي، والتصدير يفحص صلاحية المراجع.
5. **Anomaly:** طرق Rust معلنة ومحددة الإعدادات، تخرج findings وصفوفًا وأسبابًا وأثرًا مقترحًا، لا تعدّل الأصل. قبول تصحيح ينتج transformation قابلًا للتراجع.
6. **واجهة:** ترجمة ورسائل خطأ مسجلة، معاينة قبل التطبيق، ورفض مفهوم دون كشف بيانات في logs.

## المواضع المتوقعة

- عقد DSL والـvalidators في طبقة Rust المالكة للتنفيذ بعد Phase 1؛ جسر sf-wasm لا يعيد تعريف دلالات الحساب.
- واجهة أوامر ومراجع سرد في وحدات studio القائمة؛ إعادة استخدام token resolver نفسه لكل المخرجات.
- محرك الشذوذ في حزمة قائمة مناسبة، أو sf-detect فقط بعد حسم حوكمة المجلدات المؤجلة؛ لا تقرير T مزور.
- اختبارات Rust/Vitest/متصفح وملفات ICU وتوثيق DSL؛ لا تغييرات إنتاجية.

## إثبات الإنجاز

- أمثلة عربية وإنجليزية فعلية، مع نتائج محسوبة من بيانات اصطناعية قابلة للتحقق.
- رفض command unknown/unknown field/مرجع مفقود/دورة/نوع خاطئ/تعقيد زائد، وعدم وجود تعديل جزئي.
- حقن تعليمات داخل خلية لا يحوّل البيانات إلى أوامر، وAI لا يغير token أو metric.
- تغيير المصدر يحدّث السرد ويكشف المراجع غير الصالحة؛ لا رقم تحليلي حر ينسب للحقيقة بلا مرجع.
- الشذوذ لا يصحح دون موافقة، وundo يعيد الحالة؛ توثيق false positives والتمييز بين تنبؤ وحقيقة.
- gates كاملة وتقرير SHA/CI فعلي قبل Phase 3؛ لا وصف عدم توفر النموذج بأنه نجاح جزئي.
