# خطة STUDIO-Phase-3

**الحالة:** مكتملة ومحصّنة ومختبرة (2026-11-15، مراجعة v6) — المحررات الأربعة داخل `DesktopStudio.tsx` (`DashboardChartsView` بجميع الأنواع الـ 8 المحسوبة في Rust عبر `studio_chart_data`, `KeynoteSlidesView`, `VerifiedDocView`, `FreeFormBuilderView` مع تحكم كامل في العرض والارتفاع `colSpan`/`rowSpan`)، عمليات أعمدة الجدول، وحفظ المشاريع ذرياً ببصمة `BLAKE3`.  
**العقد:** [المهمة](../tasks/STUDIO-Phase-3.md).

## التصميم

الأربع Views إسقاطات لنفس StudioProject. dataset/tokens ملك Rust؛ تعديل المظهر والـBlocks لا يغير الأصل. معرفات العناصر والمقاييس مستقرة في التخزين، لا DOM state كمصدر حقيقة.

## خطوات التنفيذ

1. **CleanSheet:** ربط grid المعتمد بتعديل DataGraph وفلاتره وفرزه والبحث؛ عرض الصفحات أو النافذة المطلوبة فقط، والحالة/الفروق/الأخطاء/الأصل. أوامر أعمدة وصيغ مع تحقق صلاحيات المشروع، لا صلاحية مشتقة من UI وحده.
2. **Dashboard:** وصف رسم يضم النوع والمحاور والتجميع والفرز والفلاتر/المجموعات والعرض. Rust يحسب الناتج؛ renderer يستقبل نتائج فقط. فلاتر متبادلة وdrill-down بعقد source/dependencies نفسه.
3. **Slides:** نموذج scenes وعناصر typed وروابط metrics، ترتيب/نسخ/حذف ومحرر نصوص/قوائم/صور/رسوم، ومعاينة fullscreen وتنقل وحفظ.
4. **Document:** Blocks منظمة ومحرر موثوق أو أوامر Blocks مستقرة، لدعم الأنواع والبحث/الاستبدال/التنسيق/الترتيب، لا contentEditable منفردًا.
5. **Free-Form:** إحداثيات وأحجام وترتيب طبقات وخصائص قابلة للحفظ؛ السحب مع بدائل أزرار/لوحة مفاتيح وحدود واضحة؛ إدراج مقياس يبقي المرجع إلا عند فصل صريح.
6. **History:** أوامر تحرير قابلة للعكس للتخطيط/النص مستقلة عن تحويل البيانات، وتجميع فعل المستخدم في عملية undo واحدة واضحة.
7. **Persistence:** توسيع مخزن Phase 1 لجميع views/assets/layout/template/scenarios/settings؛ معاملات تحفظ المشروع كوحدة مترابطة، validation عند القراءة ورفض إصدار غير معروف بدل فقده.
8. **واجهة:** ترجمة ICU وbrand/tokens، RTL/LTR وثيمين وتقليل حركة وتركيز غير محجوب، واختبار الرحلة اليدوية دون AI وقوالب.

## الملفات

تعديل وحدات studio/store/worker/persistence من المراحل السابقة، وإعادة استخدام CleaningStudio/ChartsStudio ومكوّنات العرض المناسبة بدل إنشاء نسخ موازية. وحدات جديدة للشرائح/المستند/scene commands فقط حيث لا يوجد تنفيذ. ملفات ICU واختبارات Rust/Vitest/متصفح. لا تغيير الحسابات أو الغلاف خارج نقطة الدمج المصرح بها.

## الإثبات

- اختبار جدول → Dashboard → Slides → Document على المصدر نفسه وبقيم قابلة لإعادة الحساب.
- بناء رسم بكل تجميع مطلوب وفلاتر مترابطة مع القيم المتوقعة، ثم حفظ/reload.
- CRUD وترتيب/نسخ/بحث واستبدال/صور/رسوم/metric insertion وundo/redo، مع رفض المراجع المفقودة.
- إغلاق الصفحة وفتح المشروع واستكمال التحرير؛ بقاء الأصول والمراجع والإصدارات والسيناريوهات، واختبارات quota/كتابة منقطعة.
- رحلة بناء يدوي كاملة دون AI أو قالب. gates كاملة وتقرير فعلي قبل Phase 4.
