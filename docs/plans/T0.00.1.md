# خطة `T0.00.1` — انترو متصل من أول إطار إلى الموقع

1. استخدام `public/boot.css` كمصدر واحد لإطاري HTML وReact، مع نفس الشعار والأبعاد والتقدم الصفري.
2. إزالة الستارة عبر `useLayoutEffect` قبل رسم إطار React.
3. فصل انتظار الخطوط عن timeline: تبدأ نقاط الشعار والتقدم فورًا، ويظهر النص بحركة قصيرة عند جاهزية خطوطه.
4. إلغاء مؤقت الثانية وتقليل الحركات الزخرفية حتى لا تنافس الحركة الرئيسية.
5. تسخين dynamic import للصفحة أثناء الانترو، مع منع mount حتى اكتمال الدخول.
6. إضافة حالة خروج مستقلة: تركيب الصفحة تحت الانترو، ثم حركة خروج قصيرة للستار والمحتوى، ثم unmount بعد callback الاكتمال.
7. تحديث اختبار Chromium ليقيس تطابق HTML/React، وبدء الحركة الفوري، ووجود الصفحة أثناء الخروج، واكتمال الشريط والتسليم.
8. تشغيل اختبارات الحزمة وTypeScript والبناء واختبار Chromium، ومراجعة لقطات البداية والانتقال والنهاية.
