# خطة تنفيذ `T0.00` — فصل إقلاع الانترو عن التطبيق

## الهدف
منع التنافس على CPU/RAF أثناء أول لحظات الانترو، وتثبيت قياسات النص قبل الحركة، مع الاحتفاظ بنفس الهوية البصرية وتجربة الدخول.

## التشخيص المعتمد من main
- `App.tsx` يستورد ويركب `AmbientBackground` و`SmoothScrollProvider` وجميع الاستوديوهات قبل إغلاق الانترو.
- `AmbientBackground` يبدأ Canvas RAF وحسابات الجسيمات على كل إطار.
- `SmoothScrollProvider` يبدأ Lenis ويربطه بـ GSAP Ticker أثناء الانترو.
- `BlurWordText` يقسم عنوان الانترو إلى كلمات منفصلة ويبدأ GSAP قبل التحقق من جاهزية الخط.
- العنوان يمزج العربية والإنجليزية دون عزل اتجاه صريح.
- النقر على خلفية الانترو كلها ينفذ الإغلاق.

## خطوات التنفيذ
1. إنشاء `ApplicationShell.tsx` ونقل شجرة التطبيق الحالية إليه دون تغيير وظائفها.
2. جعل `App.tsx` منسق الإقلاع فقط، وتحميل `ApplicationShell` ديناميكيًا بعد اكتمال حركة الانترو.
3. إبقاء الانترو ظاهرًا أثناء تحميل التطبيق، ثم إزالتها بعد أول تركيب فعلي للتطبيق.
4. انتظار `document.fonts.load` و`document.fonts.ready` للخطوط المستخدمة قبل إظهار النص وتشغيل GSAP.
5. استبدال التقسيم إلى كلمات بعنوان HTML مستقر، مع `bdi` منفصل للعربية والإنجليزية.
6. جعل Timeline واحدة قابلة للإلغاء، وإزالة إغلاق الخلفية، والإبقاء على زر التخطي.
7. تحديث اختبارات SSR للتأكد من أن أول Render لا يركب شجرة التطبيق، وإضافة اختبارات لبنية العنوان وسلوك اتجاهاته.
8. تثبيت إطار أولي ساكن لمدة 1000ms بعد جاهزية الخطوط، وإيقاف الدوران والنبض ولمعة الانتظار خلاله.
9. تمديد حركة الشريط إلى 2.25 ثانية، وتثبيت `scaleX: 1` صراحة عند اكتمال الـTimeline، ثم إبقاءه مكتملًا 220ms قبل التسليم.
10. إضافة اختبار Chromium على نسخة الإنتاج مع تعطيل الكاش ومحاكاة بطء الشبكة/المعالج، وحفظ صور إطار التوقف وإطار اكتمال الشريط.

## التحقق
- فحص TypeScript وPrettier.
- اختبارات حزم الويب.
- بناء Web UI.
- مراجعة GitHub Actions بعد الدفع إلى `main`.
- اختبار Chromium بملف مستخدم جديد، وكاش معطل، وشبكة أبطأ ومعالج أبطأ.
- التأكد من مرور ثانية التوقف بعد جاهزية الخطوط، وقياس عرض الشريط النهائي مقارنة بعرض المسار، ومراجعة لقطات الشاشة قبل القبول.

## قيود التنفيذ
- تنفيذ مباشر على `main` حسب توجيه المالك.
- لا إنشاء فروع ولا تعديل قاعدة البيانات ولا تغيير وظائف التطبيق.
- لا تخفيف بوابات CI أو ادعاء نجاح اختبار لم يُشغّل.
