# خطة تنفيذ المهمة `T1.01` — حزمة رموز التصميم (`@safi/design-tokens`) وفحص التباين الآلي

## 1. الهدف والنطاق الحصري
تنفيذ المهمة **`T1.01` فقط** من جدول الشريحة `S1` (القسم 19.7) لبناء نظام رموز التصميم الكامل داخل `packages/design-tokens` بإشراف مهارة **`UI/UX Pro Max`** ومهارة **`I-Have-ADHD`**، وتصديره كمتغيرات CSS متوافقة مع **Tailwind CSS v4** وكأنواع وثوابت **TypeScript 5.8 (strict)**، مع ربط فاحص التباين القياسي (**WCAG 2.2 AA**) ببوابة `make check`.

### قيود النطاق الصارمة (Zero Scope Creep)
- يُحظر تعديل أي حزمة أخرى في `packages/*` أو `crates/*` أو `apps/*` خارج `packages/design-tokens`.
- يقتصر التعديل خارج `packages/design-tokens` على ما يلزم لربط فحص التباين الآلي في `package.json` و`Makefile` وتوثيق السجل والتقرير (`CHANGELOG.md`, `docs/plans/T1.01.md`, `docs/reports/T1.01.md`).
- لا يُبدأ أي عمل يخص `T1.02` أو `T1.13` أو غيرهما.

### ب. رموز الخطوط والمقاييس (`packages/design-tokens/src/typography.ts` — القسم 6.3)
- **عائلات الخطوط المحلية**:
  - العربي (`fontSansAr`): `"IBM Plex Sans Arabic", "Noto Sans Arabic", sans-serif`
  - البديل العربي الصريح (`fontSansArFallback`): `"Noto Sans Arabic", sans-serif`
  - اللاتيني (`fontSansLatin`): `"Inter", sans-serif`
  - المدمج ثنائي اللغة (`fontSans`): `"IBM Plex Sans Arabic", "Noto Sans Arabic", "Inter", sans-serif`
- **ميزة الأرقام الجدولية**: `fontVariantNumeric: "tabular-nums"` و`fontFeatureSettings: '"tnum" 1'`.
- **سلّم المقاسات (8 مقاسات بالبكسل والـ `rem`)**: `12 / 13 / 14 (الأساس) / 16 / 20 / 24 / 32 / 48`.
- **ارتفاعات الأسطر**: `1.6` للنص العربي (`ar`) و`1.45` للنص اللاتيني (`latin`).
- **الأوزان المسموحة حصريًا**: `400` (`regular`)، `500` (`medium`)، `600` (`semibold`).

### ج. شبكة المسافات والكثافة والزوايا والظلال والزجاج والإتاحة (`packages/design-tokens/src/spacing.ts` — القسمان 6.3 و18.9)
- **شبكة المسافات (4 بكسل)**: `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64` بكسل.
- **كثافتا العرض («مريح» `comfortable` و«مدمج» `compact`)**:
  - تغيّر الكثافة فعليًا سلّم المسافات الدلالية (حشو الخلايا، ارتفاع الصف، حشو البطاقات واللوحات، الفجوات بين العناصر) وفق القسم 18.9.
- **أنصاف أقطار الزوايا (`radii`)**:
  - `field`: `6px` (للحقول)
  - `card`: `10px` (للبطاقات)
  - `panel`: `16px` (للّوحات)
  - `pill`: `999px` (للأقراص)
- **الظلال (`shadows`)**:
  - الفاتح: `e1 = 0 1px 2px rgba(15,23,42,.06)`، `e2 = 0 4px 12px rgba(15,23,42,.08)`، `e3 = 0 12px 32px rgba(15,23,42,.14)`.
  - الداكن: تُستبدل بحدود وتوهج خافت (`0 0 0 1px ...` مع توهج ناعم).
- **طبقات الزجاج (`glass`)**:
  - `blur`: `20px`، `opacity`: `0.72` (للشريط العلوي والقوائم فقط)، مع بديل إلغاء الشفافية (`opacity: 1`, `blur: 0px`) عند تفعيل المستخدم «تقليل الشفافية».
- **ثوابت الإتاحة التفاعلية (الأقسام 6.1، 6.5، 6.8، 18.1 `ن5`، 18.9)**:
  - الحد الأدنى لهدف اللمس/النقر: `44px` (`minTouchTargetPx: 44`).
  - الفاصل الأدنى بين الأهداف: `8px` (`minTargetGapPx: 8`).
  - سمك حلقة التركيز: `2px` (`focusRingWidthPx: 2`).
  - إزاحة التمرير للشريط العلوي الثابت (`scrollPaddingTopPx: 56`) لمنع حجب التركيز (`WCAG 2.4.11`).

### د. رموز الحركة (`packages/design-tokens/src/motion.ts` — القسم 6.4)
- **المدد الزمنية**:
  - `instant`: `100ms` (تغيّر حالة زر، تحديد)
  - `fast`: `160ms` (قوائم وتلميحات)
  - `base`: `240ms` (دخول العناصر وتبديل التبويبات)
  - `slow`: `360ms` (الأدراج واللوحات الجانبية)
  - `deliberate`: `520ms` (الانتقال بين الشاشات الكبرى)
- **المنحنيات (`easings`)**:
  - `standard`: `cubic-bezier(0.2, 0, 0, 1)`
  - `enter`: `cubic-bezier(0.05, 0.7, 0.1, 1)`
  - `exit`: `cubic-bezier(0.3, 0, 1, 1)`
- **النابض (`spring`) للسحب والإفلات**: `stiffness: 260`, `damping: 26`.
- **معاملات الدخول والتتابع**: مسافة الانزلاق `8px` إلى `16px`، فارق القوائم `24ms` حتى `8` عناصر كحد أقصى، والخصائص المسموحة `transform` و`opacity` فقط بسرعة `60fps`.
- **بديل تقليل الحركة (`prefers-reduced-motion: reduce`)**: استبدال كل حركة بتلاشٍ مدته `120ms` (`reducedMotionFadeMs: 120`) وإلغاء الانزلاق والحركات الزخرفية (`slideDistancePx: 0`).

### هـ. التصدير لـ Tailwind CSS v4 وTypeScript (`src/css.ts` و`src/tokens.css`)
- بناء مولّد نص CSS حتمي (`generateTokensCss()`) وملف CSS ثابت (`packages/design-tokens/src/tokens.css`) يتضمن:
  - تعريفات `:root` و`[data-theme="light"]` للوضع الفاتح، و`[data-theme="dark"]` و`@media (prefers-color-scheme: dark)` للوضع الداكن.
  - تعريفات `[data-density="comfortable"]` و`[data-density="compact"]` لكثافتي العرض.
  - تعريفات `@media (prefers-reduced-motion: reduce)` و`@media (prefers-reduced-transparency: reduce)` و`[data-reduced-transparency="true"]`.
  - كتلة `@theme` الخاصة بـ **Tailwind CSS v4** لربط متغيرات `--sf-*` بأسماء فئات Tailwind القياسية (`--color-*`, `--font-*`, `--text-*`, `--radius-*`, `--shadow-*`, `--ease-*`, `--spacing-*`).

### و. فاحص التباين الآلي وربطه بـ `make check` (`src/contrast.ts` و`src/verify-contrast.ts`)
- تنفيذ خوارزمية WCAG 2.2 القياسية لحساب اللمعان النسبي (`relativeLuminance`) ونسبة التباين (`contrastRatio`).
- التحقق الآلي من:
  1. جميع أزواج النصوص (`textPrimary`, `textSecondary`, `textMuted` على `bg`, `surface`, `surface2` وعلى `primarySoft`، وأزواج النصوص على الأزرار الرئيسية) بشرط **$\ge 4.5:1$** في الوضعين الفاتح والداكن.
  2. جميع عناصر الواجهة والرسوم (`primary`, `primaryHover`, `success`, `warning`, `danger`, `info` على `bg`, `surface`, `surface2`) بشرط **$\ge 3.0:1$** في الوضعين الفاتح والداكن.
- توفير وضع اختبار ذاتي (`--self-test`) يزرع لون نص مخالفًا (`#64748B` على `#F5F7FA` بتباين `4.45:1` < `4.5:1`) ولون رسم مخالفًا (`< 3.0:1`) ويتأكد من أن الفاحص يكتشفهما ويرفض البناء.
- ربط `pnpm --filter @safi/design-tokens run check:contrast` (ومعه `--self-test`) داخل هدف `check` في `Makefile`.
