# خطة تنفيذ المهمة `T1.04` — محرك استيراد CSV بالبث وكشف الترميز والفاصل (`crates/sf-io`)

## 1. الهدف والنطاق الحصري
تنفيذ المهمة **`T1.04` فقط** من الشريحة `S1` (القسم 19.7) لبناء حزمة **`crates/sf-io` حصريًا** لمعالجة واستيراد ملفات `CSV` و`TSV` و`TXT` المفصول وفق القسم 4.2، مع:
1. الكشف التلقائي الدقيق للترميز (`UTF-8` مع/بدون BOM، و`Windows-1256`) وإطلاق رمز الخطأ المعتمد `SF-IMP-002` عند انخفاض الثقة.
2. الكشف التلقائي للفاصل (`Comma ,`، `Semicolon ;`، `Tab \t`) وصف الترويسة وتجاوز الأسطر الوصفية التمهيدية.
3. استيراد بالبث (`Streaming Reader`) ودفعات (`chunks`) لمعالجة الملفات الكبيرة بكفاءة عالية وذاكرة منخفضة.
4. فرض حدود الحجم للمنصة (`PlatformLimits`) واستدعاء رمز الخطأ القياسي `SF-IMP-003` عند تجاوز الحد المسموح.
5. ربط البيانات المستوردة مع الهياكل الأساسية في `crates/sf-core` (`Table`, `Column`, `CellValue`, `ZeroPreservedText`) بحتمية تامة وصفر اعتماديات شبكة.

### قيود النطاق الصارمة (Zero Scope Creep)
- النطاق محصور حصريًا داخل `crates/sf-io` (مع تثبيت الاعتماديات الدقيقة `csv = "=1.3.1"`, `encoding_rs = "=0.8.35"`, `chardetng = "=0.1.7"` في `Cargo.toml` وربطها بالمسار).
- **لا يُلمس** قارئ `XLSX` أو فك الخلايا المدمجة (يخص المهمة `T1.05`).
- **لا يُكتب** منطق التنضيف العربي أو توحيد الهمزات (يخص المهمة `T1.06`).
- **صفر اعتماديات شبكة** داخل محرك Rust (`tools/check-no-network.sh` يجب أن ينجح بالكامل).

## 3. التصميم التفصيلي للمخرجات داخل `crates/sf-io`

### أ. هيكل الحزمة والاعتماديات (`crates/sf-io/Cargo.toml`)
- الاعتماديات الدقيقة المبيّنة في المواصفة (بدون أي اعتمادية شبكة):
  - `sf-core` (مسار محلي `= "0.1.0"`)
  - `csv = "=1.3.1"`
  - `encoding_rs = "=0.8.35"`
  - `chardetng = "=0.1.7"`

### ب. وحدات المعالجة (`crates/sf-io/src/`)
1. **`encoding.rs`**:
   - كشف الترميز باستخدام `chardetng` و`encoding_rs` لدعم `UTF-8` (مع أو بدون BOM) و`Windows-1256` (للملفات العربية القديمة).
   - إطلاق `SafiError` برمز الخطأ `SF-IMP-002` عند انخفاض الثقة أو عدم التعرف على الترميز.
2. **`delimiter.rs`**:
   - كشف الفاصل التلقائي (`comma`, `semicolon`, `tab`) عبر تحليل السطور الأولى وعينة العينات.
3. **`reader.csv.rs`**:
   - قارئ `CSV` بالبث (`streaming`) والدفعات (`chunks`) لضمان عدم استهلاك الذاكرة للملفات الكبيرة.
   - احترام حدود المنصة (`PlatformLimits::validate`) وإطلاق رمز الخطأ `SF-IMP-003` عند تجاوز الحجم أو الصفوف.
   - تحويل خلايا الملف إلى `CellValue` مع الحفاظ على النص الأصلي ودعم الأصفار البادئة عبر `sf-core`.
4. **`lib.rs`**:
   - التصدير العام لواجهات الاستيراد واختبارات الوحدات الشاملة (ملفات اختبار عربية بترميزين UTF-8 وWindows-1256 وبفواصل مختلفة).

## 4. خطوات التنفيذ والتحقق
1. إنشاء مجلد وحزمة `crates/sf-io` مع `Cargo.toml` الملتزم بالإصدارات الدقيقة.
2. تنفيذ الوحدات (`encoding.rs`, `delimiter.rs`, `reader.csv.rs`, `lib.rs`).
3. كتابة اختبارات وحدات شاملة في `crates/sf-io` تتضمن ملفات CSV عربية بترميز UTF-8 وWindows-1256.
4. تشغيل `cargo test -p sf-io` و`bash tools/check-no-network.sh` و`make check`.
5. تحديث `CHANGELOG.md` بسطر عربي بسيط، كتابة `docs/reports/T1.04.md` وتوثيق العمل.
