# خطة تنفيذ المهمة `T1.06` — حزمة التطبيع والتنضيف العربي (`sf-arabic`)

## 1. الهدف والنطاق الحصري
تنفيذ المهمة **`T1.06` فقط** من الشريحة `S1` (القسم 19.7) لتوسيع حزمة **`crates/sf-arabic` حصريًا** بمحرك التطبيع والتنضيف اللغوي العربي وفق القسم 4.4 من المواصفة، موفّراً:
1. **القاعدة الذهبية**: النص الأصلي يُحفظ دائمًا دون مساس، وتُحسب نسخة «موحَّدة» للمطابقة فقط، مع توفير خيار قابل للضبط لاستبدال النص الظاهر عند طلب المستخدم.
2. **توحيد الحروف العربية**: توحيد الألف (`أ`, `إ`, `آ`, `ٱ` إلى `ا`)، وتوحيد (`ى` إلى `ي`) وتوحيد (`ة` إلى `ه`) في آخر الكلمة، مع خيار قابل للضبط لتوحيد الهمزة على واو (`ؤ`) أو ياء (`ئ`).
3. **إزالة التطويل والتشكيل**: إزالة التطويل (`ـ` / الكشيدة) وكافة حركات التشكيل العربية (الفتح، الضم، الكسر، التنوين، السكون، الشدة، إلخ).
4. **تنظيف المسافات والأحرف غير المرئية**: حذف المسافات المتكررة، مسافات `NBSP`، والأحرف غير المرئية (`ZWJ`, `ZWNJ`, علامات الاتجاه `RLM`, `LRM`, وعلامات التحكم `Bidi`) دون المساس بالترتيب المنطقي للحروف.
5. **تطبيع الأرقام والرموز**: تحويل الأرقام العربية المشرقية والهندية (`٠-٩` و`۰-۹`) إلى أرقام لاتينية (`0-9`) أو العكس حسب إعداد العرض، وتوحيد الفاصلة العشرية العربية (`٫`) وفاصلة الآلاف (`٬`) وعلامة الاستفهام (`؟`).
6. **معالجة الأسماء المركبة والألقاب**: ضم الأسماء المركبة منطقيًا («عبد»، «أبو»، «أم» مع الكلمة التالية)، وتوفير خيار لحذف الألقاب الشائعة (`د.`, `م.`, `أ.`, `الأستاذ`, إلخ).
7. **اختبارات الخصائص الآلية (`proptest`)**: إضافة `proptest` كمكتبة تطوير مقفولة النسخة وإثبات حتمية التطبيع وخاصية الثبات (`Idempotence`): `normalize(normalize(s)) == normalize(s)`.

### قيود النطاق الصارمة (Zero Scope Creep)
- النطاق محصور حصريًا داخل `crates/sf-arabic`.
- **لا يُبنى** محقّق الرقم القومي المصري الكامل (فهو يخص المهمة `T2.13` في الشريحة `S2`).
- **لا تُبنى** خوارزمية المطابقة التقريبية `Jaro-Winkler` والمفتاح الصوتي المصري (فهي تخص المهمة `T2.14`).
- **صفر اعتماديات شبكة** داخل محرك Rust (تجاوز `tools/check-no-network.sh`).

## 3. التصميم التفصيلي للمخرجات داخل `crates/sf-arabic`

### أ. الاعتماديات في `crates/sf-arabic/Cargo.toml`
- إضافة `proptest = "=1.5.0"` ضمن `[dev-dependencies]` لإجراء اختبارات الخصائص (`Idempotence`).

### ب. وحدات الحزمة (`crates/sf-arabic/src/lib.rs` أو وحدات فرعية)
1. `ArabicNormalizer` مع خيارات ضبط (`NormOptions`):
   - `unify_alif`: توحيد أشكال الألف إلى `ا`.
   - `unify_ya_alif_maksura`: توحيد `ى` إلى `ي`.
   - `unify_ha_ta_marbuta`: توحيد `ة` إلى `ه`.
   - `remove_tatweel`: إزالة الكشيدة (`ـ`).
   - `remove_diacritics`: إزالة التشكيل.
   - `clean_whitespace`: إزالة المسافات الزائدة والأحرف غير المرئية.
   - `normalize_digits`: توحيد الأرقام المشرقية/الهندية إلى لاتينية (أو العكس).
   - `join_compound_names`: ضم «عبد»، «أبو»، «أم» مع ما يليها.
   - `remove_titles`: حذف الألقاب (`د.`, `م.`, إلخ).

## 4. خطوات التنفيذ والتحقق
1. تحديث `crates/sf-arabic/Cargo.toml` لإضافة `proptest`.
2. تنفيذ وظائف التطبيع والتنضيف العربي في `crates/sf-arabic`.
3. كتابة اختبارات وحدات واختبارات خصائص (`proptest`) تثبت خاصية الثبات (`normalize(normalize(s)) == normalize(s)`).
4. تشغيل `cargo test -p sf-arabic` و`bash tools/check-no-network.sh` و`make check`.
5. تحديث `CHANGELOG.md`، كتابة `docs/reports/T1.06.md` والتوقف لانتظار الموافقة.
