# خطة تنفيذ المهمة `T1.07` — محرك تعرّف وفهم أنواع الأعمدة (`crates/sf-profile`)

## 1. الهدف والنطاق الحصري
تنفيذ المهمة **`T1.07` فقط** من الشريحة `S1` (القسم 19.7) لتوسيع حزمة **`crates/sf-profile` حصريًا** بمحرك استنتاج وتعرّف أنواع الأعمدة ودرجات الثقة والأدلة (القسمين 4.3 و16.1)، موفّراً:
1. **فحص العينات حتى 10 آلاف قيمة** لكل عمود واستنتاج نوع العمود (`Text`, `Name`, `Date`, `Number`, `Amount`, `EgyptianPhone`, `Email`, `Id`, `Category`, `Boolean`, `Unknown`, وغيرها وفق `sf-core`).
2. **قاموس مرادفات العناوين**: الاستعانة باسم العمود كدليل إضافي عبر قاموس مرادفات عربي وإنجليزي («الاسم»، «Name»، «م»، «ت»، «التاريخ»، «المبلغ»، «الهاتف»، إلخ).
3. **عقد الفهم والعتبات (القسمين 4.3 و16.1)**:
   - ثقة $\ge 0.8$: يُطبَّق الاستنتاج تلقائيًا.
   - ثقة بين $0.5$ و$0.8$: يُعرض للمستخدم ليؤكد.
   - ثقة $< 0.5$: يُصنَّف العمود `Unknown` ويُعطى رمز الخطأ المعتمد `SF-PRF-001`.
   - كل استنتاج يحمل درجة ثقة، ودليلًا (عينات القيم والأنماط الداعمة)، وبدائل محتملة.
4. **حماية المعرّفات والأصفار البادئة**: تمييز أعمدة المعرّفات والأرقام القومية والهواتف لضمان حفظها كنصوص دائمًا دون إزالة الأصفار البادئة.
5. **المجموعة الذهبية للأعمدة وقياس الدقة**: بناء مجموعة اختبار ذهبية داخل `crates/sf-profile` وقياس دقة التعرّف آليًا وتسجيل النتيجة في التقرير.

### قيود النطاق الصارمة (Zero Scope Creep)
- النطاق محصور حصريًا داخل `crates/sf-profile` (مع الاعتماد على `sf-core` و`sf-arabic`).
- **لا تُكتب** عمليات التنظيف والتراجع (`sf-clean` تتبع المهمة `T1.08`).
- **صفر اعتماديات شبكة** داخل محرك Rust.

### ب. وحدات الحزمة الجديدة (`crates/sf-profile/src/lib.rs` و `profiler.rs`)

3. تطبيق العتبات ($0.8$ و$0.5$) وإنشاء رمز الخطأ `SF-PRF-001` للأنواع غير المعروفة.
4. المجموعة الذهبية للاختبارات وقياس الدقة.
