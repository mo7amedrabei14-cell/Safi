# خطة تنفيذ المهمة `T1.08` — محرك العمليات الخمس للتنضيف والتراجع بالفروقات (`crates/sf-clean`)

## 1. الهدف والنطاق الحصري
تنفيذ المهمة **`T1.08` فقط** من الشريحة `S1` (القسم 19.7) لتوسيع حزمة **`crates/sf-clean` حصريًا** بتنفيذ العمليات الخمس للتنضيف وتخزين التراجع كفروقات (`deltas`) وفق الأقسام 4.5 و4.6 و4.7 و4.10، موفّراً:
1. **العملية الأولى (توحيد النص العربي)**: تطبيق تطبيع `sf-arabic` مع حفظ النص الأصلي دائمًا وتوفير خيار تحديث النص الظاهر بناءً على طلب المستخدم.
2. **العملية الثانية (حذف المكرر الدقيق وبعد التوحيد)**: اكتشاف مجموعات الصفوف المكررة تطابقًا دقيقًا أو بعد التوحيد العربي، ودعم اختيار الصف الباقي (الأول، الأكمل، الأحدث) كخطوة قابلة للتراجع دون حذف صامت.
3. **العملية الثالثة (معالجة الفراغات - القسم 4.7)**: معاملة الرموز (`-`, `N/A`, `لا يوجد`, `غير متوفر`) كفراغ، ودعم خيارات الملء الخمسة (القيمة السابقة للخلايا المدمجة، المتوسط، الوسيط، الأكثر تكرارًا، أو الترك)، مع فرض قاعدة منع ملء أعمدة الهوية والمعرّفات نهائيًا.
4. **العملية الرابعة (توحيد التواريخ - القسم 4.5)**: دعم صيغ `d/m/y` و`m/d/y` و`ISO` وأسماء الشهور العربية والتاريخ الهجري والأرقام التسلسلية لـ Excel وتوحيدها إلى `ISO 8601`، وحسم غموض اليوم/الشهر بتحليل العمود كاملًا، أما الغموض الحقيقي فيُبلَّغ عنه برمز الخطأ `SF-CLN-001` ويُعرض للمستخدم ولا يُحسم صامتًا.
5. **العملية الخامسة (توحيد الأرقام والعملات والهواتف - القسم 4.5)**: تحليل الأرقام بفواصل المناطق والأرقام الهندية ورموز العملات (`ج.م`, `جنيه`, `EGP`, `$`, `ر.س`) والأقواس للسالب وتخزين المبالغ بنوع `Decimal` لا `float`، وتطبيع الهواتف المصرية إلى صيغة `E.164` مع عدم حذف الأصفار البادئة أبدًا.
6. **سجل التغييرات والتراجع بالفروقات (`Deltas` - القسم 4.10)**: تسجيل عدد الخلايا المتأثرة وعينة (قبل/بعد) ومدة التنفيذ، وتخزين التراجع كفروقات (`deltas`) وليس كنسخ كاملة، وتوفير دالة تراجع (`undo`) تعيد الجدول إلى حالته الأصلية بايتًا ببايت.
7. **اختبارات القبول والخصائص (`proptest`)**: إثبات أن تطبيق أي سلسلة من العمليات الخمس ثم التراجع عنها يعيد الجدول الأصلي تمامًا دون أي فقد، وأن التواريخ الغامضة تطلق `SF-CLN-001`.

### قيود النطاق الصارمة (Zero Scope Creep)
- النطاق محصور حصريًا داخل `crates/sf-clean`.
- **لا يُبنى** محرك الوصفات JSON (`sf-recipe` يتبع المهمة `T1.09`) ولا المطابقة التقريبية `Jaro-Winkler` (تخص `T2.14`).
- **صفر اعتماديات شبكة** داخل محرك Rust.

## 4. خطوات التنفيذ والتحقق
1. تحديث `crates/sf-clean/Cargo.toml`.
2. تنفيذ العمليات الخمس ونظام Deltas والتراجع في `crates/sf-clean`.
3. كتابة اختبارات الوحدات واختبارات الخصائص (`proptest`) للتحقق من التراجع المطلق ومعالجة التواريخ الغامضة (`SF-CLN-001`).
4. تشغيل `cargo test -p sf-clean` و`bash tools/check-no-network.sh` و`make check`.
5. تحديث `CHANGELOG.md`، كتابة `docs/reports/T1.08.md` والتوقف لانتظار الموافقة.
