# خطة تنفيذ المهمة `T1.10` — حزمة جودة البيانات وتوليد التقارير المتجهية العربية بـ `Typst` (`crates/sf-report`)

## 1. الهدف والنطاق الحصري
تنفيذ المهمة **`T1.10` فقط** من الشريحة `S1` (القسم 19.7) لتوسيع حزمة **`crates/sf-report` حصريًا** بحساب درجة جودة البيانات وفق القسم 4.11 وتوليد تقارير PDF عربية متجهية فورية باستخدام محرك `Typst` المضمّن في Rust (القسم 17)، موفّراً:
1. **حساب درجة جودة البيانات (0 إلى 100)** وفق القسم 4.11:
   - الاكتمال (`25%`)
   - الاتساق (`25%`)
   - الصلاحية (`20%`)
   - التفرّد (`15%`)
   - المنطقية (`15%`)
   - حساب الدرجة الإجمالية وللكل عمود، مع تقديم ملخص تفصيلي بما ينقص لرفع الدرجة.
2. **ملخص الأعداد قبل وبعد**: مقارنة حالة الجدول قبل وبعد التنظيف (إجمالي الصفوف، المكررات، الفراغات، الخلايا المصححة، وفرق درجة الجودة).
3. **توليد تقرير PDF عربي متجهي فوري**: صفحة واحدة باتجاه من اليمين لليسار (`RTL`) عبر محرك `Typst` المضمّن في أقل من 100 مللي ثانية مع وصل صحيح للحروف العربية ودون طباعة متصفح.
4. **اختبارات القبول والأداء**: اختبارات وحدات لتحقق دقة معادلة الجودة وسلامة توليد ملف الـ PDF ضمن ميزانية الأداء وصفر اعتماديات شبكة.

### قيود النطاق الصارمة (Zero Scope Creep)
- النطاق محصور حصريًا داخل `crates/sf-report`.
- **لا يُبنى** جسر الويب `sf-wasm` (يتبع المهمة `T1.11`).
- **صفر اعتماديات شبكة** داخل محرك Rust.

## 4. خطوات التنفيذ والتحقق
1. تحديث `crates/sf-report/Cargo.toml`.
2. تنفيذ معادلة جودة البيانات وملخص المقارنة وتوليد PDF بـ `Typst`.
3. كتابة اختبارات الوحدات لضمان دقة الحساب وتوليد الـ PDF ضمن ميزانية الأداء.
4. تشغيل `cargo test -p sf-report` و`bash tools/check-no-network.sh` و`make check`.
5. تحديث `CHANGELOG.md`، كتابة `docs/reports/T1.10.md` والتوقف لانتظار الموافقة.
