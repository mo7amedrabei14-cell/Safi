# خطة تنفيذ المهمة `T1.12` — حزمة التدويل والتدقيق اللغوي ICU (`packages/i18n`)

---

## 1. الهدف والمخرجات المطلوبة
- تطوير حزمة التدويل والتدقيق اللغوي `@safi/i18n` لتدعم ICU MessageFormat وصيغ الجمع العربية الست (`zero`, `one`, `two`, `few`, `many`, `other`)، مع العربية لغة أولى افتراضية والإنجليزية لغة ثانية.
- توفير ملفات القواميس الأساسية `packages/i18n/locales/ar.json` و `packages/i18n/locales/en.json` باصطلاح المفاتيح `area.component.element` وتغطية الشاشة الرئيسية، التنظيف، لوحة الفهم، التصدير والأخطاء.
- توفير مزوّد حالة تفاعلي لـ React (`I18nProvider` وخطّاف `useI18n`) لتبديل اللغة واتجاه الصفحة (`dir="rtl"` و `dir="ltr"` والوسم `lang`) فورًا في الذاكرة دون إعادة تحميل للصفحة، مع دعم استقلال لغة الواجهة عن لغة البيانات ولغة التقرير.
- دالة اختبار تمديد النصوص بنسبة `40%` (`expandText40Pct`) لاختبار مرونة الواجهة.
- سكربت فحص آلي (`tools/verify-i18n.py`) مربوط ببوابة `make check` للتحقق من عدم وجود أي مفتاح ناقص، أو نص فارغ، أو عدم تطابق متغيرات `{placeholder}` في صيغ ICU.

---

## 2. خطوات التنفيذ
1. كتابة ملفات القواميس `ar.json` و `en.json` داخل `packages/i18n/locales/`.
2. تطوير محرك التدويل وتنسيق ICU وعمل مزوّد React في `packages/i18n/src/`.
3. كتابة سكربت الفحص `tools/verify-i18n.py` مع الاختبار الذاتي السلبي `--self-test`.
4. كتابة اختبارات الوحدات الشاملة بـ Vitest وتحديث `Makefile` و `CHANGELOG.md` وكتب التقرير `docs/reports/T1.12.md`.
