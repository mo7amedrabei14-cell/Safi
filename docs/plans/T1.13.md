# خطة تنفيذ المهمة `T1.13` — مكتبة مكونات واجهة المستخدم ونظام التصميم (`packages/ui` و `packages/icons`)

---

## 1. الهدف والمخرجات المطلوبة
- بناء مكونات واجهة المستخدم الأساسية داخل `packages/ui` مستندة إلى رموز التصميم (`packages/design-tokens`) والتنقل بـ RTL أولاً:
  1. `Button` (بأنواعه الخمسة مع هدف لمس 44×44 بكسل وحلقة تركيز 2 بكسل).
  2. `Dialog` (نافذة منبثقة تفاعلية بإمكانية الإغلاق ودعم WCAG 2.2 AA).
  3. `Tooltip` (تلميح توضيحي متوافق مع الاتجاهات).
  4. `Progress` (شريط تقدم خطي ودائري مع احترام `prefers-reduced-motion`).
  5. `Toast` (إشعارات منبثقة مؤقتة).
  6. `Glide Data Grid` (جدول بيانات على Canvas بسرعة 120 FPS مع دعم RTL أصلي وتثبيت العمود الأول وتلوين الفروق).
- توفير الأيقونات الاتجاهية في `packages/icons` مع الانعكاس التلقائي في اتجاه RTL.
- تنفيذ مكونات `React Bits` المرتبطة بمتغيرات Tailwind v4 (مثل عدّاد التوفير والمؤثرات البصرية).
- توثيق المكونات بـ Storybook (أو اختبارات الوحدات والإتاحة بـ Vitest) وتوفير اختبارات إتاحة آلية.

---

## 2. خطوات التنفيذ
1. إنشاء هيكل الحزم `packages/icons` و `packages/ui`.
2. تنفيذ المكونات الأساسية (`Button`, `Dialog`, `Tooltip`, `Progress`, `Toast`) مع الالتزام بمتطلبات الإتاحة (WCAG 2.2 AA).
3. تنفيذ جدول البيانات `Glide Data Grid` المعتمد على Canvas مع دعم RTL كامل.
4. تنفيذ مكونات `React Bits` وعدّاد التوفير.
5. كتابة اختبارات الوحدات والإتاحة، وتحديث `Makefile`, `CHANGELOG.md`, وكتابة التقرير `docs/reports/T1.13.md`.
