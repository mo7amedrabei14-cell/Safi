# خطة تنفيذ المهمة T1.14 — حزمة الحركة والموشن لوجو وهيكل التطبيق (apps/web)

- **معرّف المهمة**: `T1.14`
- **الشريحة**: الشريحة S1: الأساس والتنضيف والتقرير
- **الفرع**: `task/T1.14-web-shell-motion`

## 1. الأهداف الرئيسية
1. **إنشاء فرع العمل**: الانتقال إلى الفرع `task/T1.14-web-shell-motion`.
2. **بناء حزمة الحركة والموشن لوجو (`packages/motion`)**:
   - العلامة المرجعية للشعار (SVG في مساحة `128×128` بتدرج `#3CC3D6` إلى `#0B7C8C` وعلامة الصح البيضاء) وفق القسم 7.1.
   - خط زمني GSAP 3.12 (`packages/motion/src/gsap-timelines.ts`) للموشن لوجو (مدة قياسية 2.6 ثانية مع النقاط التسع والشبكة والقطرة والتموّج، و0.6 ثانية في التكرارات التالية مع إمكانية التخطي، وتلاشٍ 120 مللي ثانية عند تفعيل `prefers-reduced-motion`).
   - مزود التمرير الناعم Lenis (`packages/motion/src/lenis-provider.tsx`) بسرعة 60 إطارًا في الثانية مع الإيقاف التلقائي داخل `Glide Data Grid`.
3. **بناء هيكل `apps/web` (Vite 6 + React 19 + TanStack Router)**:
   - التوجيه الآمن بالأنواع عبر TanStack Router وزصانة الحالة عبر Zustand وTanStack Query لمسارات التطبيق الأساسية (البداية، الرئيسية، المكتبة، مساحة التنضيف، الوصفات، التقارير، الإعدادات).
   - تبديل اللغة الفوري (`ar` بـ RTL افتراضيًا و`en` بـ LTR) دون إعادة تحميل (I2)، وتبديل المظهر (فاتح وداكن وتلقائي — I3)، وتبديل كثافة العرض («مريح» و«مدمج» — 18.9).
   - الشريط العلوي الزجاجي الثابت (بارتفاع 56 بكسل وتمويه 20 بكسل) مع ضبط `scroll-padding` لعدم حجب التركيز عند التنقل بلوحة المفاتيح.
   - حدود الخطأ (`ErrorBoundary`) لالتقاط الأخطاء غير المتوقعة وعرض الشاشة العربية البسيطة مع رمز التشخيص `SF-UNK-001`.
4. **اختبارات القبول والتحقق**:
   - اختبارات Vitest للتحقق من التنقل الكامل بلوحة المفاتيح، تبديل الوضع واللغة، ومواصفات الموشن لوجو وحدود الخطأ.
