# خطة تنفيذ المهمة T1.15 — الشاشة الرئيسية ومنطقة الإفلات وجسر Web Worker

- **معرّف المهمة**: `T1.15`
- **الشريحة**: الشريحة S1: الأساس والتنضيف والتقرير
- **الفرع**: `task/T1.15-home-dropzone`

## 1. الأهداف الرئيسية
1. **إنشاء فرع العمل**: الانتقال إلى الفرع `task/T1.15-home-dropzone`.
2. **الشاشة الرئيسية ومنطقة الإفلات (`apps/web/src/pages/Home.tsx`)**:
   - منطقة إفلات متطورة تقبل حتى 50 ملفًا (ميزة A1) مع دعم السحب والإفلات، زر اختيار الملفات، ولصق الجداول مباشرة من الحافظة (ميزة A3).
   - عرض قائمة الملفات الأخيرة والقوالب المقترحة تحت منطقة الإفلات.
3. **التحقق والمعالجة عبر Web Worker (`apps/web/src/workers/safi.worker.ts` و `apps/web/src/hooks/useSafiWorker.ts`)**:
   - ربط استيراد وفحص الملفات بجسر WASM (`crates/sf-wasm`) داخل عمال الويب (`Web Workers`) مع حساب نسبة التقدم لحظيًا دون تجميد واجهة المستخدم.
4. **عرض الأخطاء بالرموز الرسمية (Specification Section 15.5)**:
   - التقاط أخطاء المحرك وعرض رسائل عربية واضحة مرفقة برمز الخطأ المعياري (مثل `SF-IMP-001` للملف التالف، `SF-IMP-003` لتجاوز حجم الملف، و`SF-IMP-005` لرفض الضغط المفخخ) مع تحديد الخطوة التالية للمستخدم.
5. **الاختبارات الآلية (`apps/web/src/pages/Home.test.ts`)**:
   - كتابة اختبارات Vitest تثبت أن رفع ملف تالف أو غير مدعوم أو تجاوز الحد يعرض الرسالة العربية الرمزية المعتمدة دون أي انهيار في الواجهة.
6. **التوثيق وتحديث التقارير**:
   - تشغيل الفحص المحلي، تحديث `CHANGELOG.md` وتوثيق تقرير المهمة في `docs/reports/T1.15.md`.
