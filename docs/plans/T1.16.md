# خطة تنفيذ المهمة T1.16 — مساحة التنضيف v1 (الشبكة، لوحة الفهم، لوحة الخطوات، المعاينة، التراجع)

- **معرّف المهمة**: `T1.16`
- **الشريحة**: الشريحة S1: الأساس والتنضيف والتقرير (أسابيع 1 إلى 4 — القسم 19.7)
- **الفرع**: `task/T1.16-cleaning-workspace`

## 1. الأهداف الرئيسية
1. **إنشاء فرع العمل**: العمل على الفرع `task/T1.16-cleaning-workspace`.
2. **بناء مساحة التنضيف (أهم شاشة في المنتج — القسم 6.5)**:
   - الشريط العلوي (ارتفاع 56 بكسل): تراجع، إعادة، حفظ كوصفة، تصدير.
   - اللوحة الجانبية للأعمدة وأنواعها (لوحة الفهم المبسطة: النوع، الثقة، زر "لماذا؟"، البدائل، وأزرار `✓` و`✗`).
   - وسط الشاشة: شبكة بيانات تفاعلية مع ترويسة لكل عمود تتضمن أيقونة النوع، شريط جودة رفيع، وقائمة إجراءات.
   - اللوحة الجانبية للخطوات والمعاينة (قبول ورفض كل خطوة، وعرض معاينة قبل وبعد).
   - عرض كل لوحة جانبية 320 بكسل مع إمكانية الطي والفتح، مع توفير بدائل بالنقر لكل سحب وإفلات التزاما بالمعيار 2.5.7 في WCAG 2.2 AA.
3. **الاختبارات الآلية**:
   - كتابة اختبارات `Vitest` للقصص 1 و2 و3 في القسم 2 (سحب الملف، رؤية الاقتراحات، قبول/رفض الخطوات مع المعاينة والتراجع).
4. **التوثيق وتحديث التقارير**:
   - تشغيل البوابة الشاملة `make check` محليًا، وتحديث `CHANGELOG.md` بسطر عربي بسيط، وتوثيق تقرير المهمة في `docs/reports/T1.16.md`.
