# خطة تنفيذ المهمة T1.18 — السجلات v1 (مسجّل JSON الموحّد، السجل المحلي الدوّار، عارض السجلات، وح اختبار حجب الأسرار)

- **معرّف المهمة**: `T1.18`
- **الشريحة**: الشريحة S1: الأساس والتنضيف والتقرير (أسابيع 1 إلى 4 — القسم 19.7)
- **الفرع**: `task/T1.18-v1-logging`

## 1. الأهداف الرئيسية
1. **إنشاء فرع العمل**: العمل على الفرع `task/T1.18-v1-logging`.
2. **مسجّل السجلات بصيغة JSON الموحّدة للمتصفح والتطبيق (القسم 15.3)**:
   - بناء هيكل السجلات المحليه بصيغة JSON مع دعم مستويات التسجيل (`INFO`, `WARN`, `ERROR`).
3. **السجل المحلي الدوّار (Rolling Log) واختبار حجب الأسرار (القسم 15.8)**:
   - تخزين السجلات في سجل محلي دوّار قابل للتصدير والحذف الآمن، مع تصفية وتنقية صارمة (`redaction`) تحجب أي كلمات سر، رموز، مفاتيح، أو بيانات حساسة وخلايا.
4. **واجهة رمز التشخيص وعارض السجلات المحلي (القسم 15.5)**:
   - إتاحة معاينة محتوى السجل ورموز التشخيص (مثل `SF-UNK-001`) قبل إرساله أو تصديره.
5. **الاختبارات الآلية**:
   - كتابة اختبار آلي يزرع أسرارًا وهمية أو بيانات حساسة ويتحقق من حجبها تمامًا وعدم ظهورها في أي سجل (معيار القبول).
6. **التوثيق وتحديث التقارير**:
   - تشغيل الفحص المحلي، تحديث `CHANGELOG.md` وتوثيق تقرير المهمة في `docs/reports/T1.18.md`.
