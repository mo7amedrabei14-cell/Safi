# خطة تنفيذ المهمة T1.19 — الأمان v1 (ترويسات CSP عبر _headers، نموذج التهديدات THREAT_MODEL.md، والتحقق الآلي)

- **معرّف المهمة**: `T1.19`
- **الشريحة**: الشريحة S1: الأساس والتنضيف والتقرير (أسابيع 1 إلى 4 — القسم 19.7)
- **الفرع**: `task/T1.19-v1-security-csp`

## 1. الأهداف الرئيسية
1. **إنشاء فرع العمل**: العمل على الفرع `task/T1.19-v1-security-csp`.
2. **ضبط ترويسات الأمان الصارمة في ملف `apps/web/public/_headers` (القسمين 8.2 و8.5)**:
   - سياسة أمان محتوى صارمة (`Content-Security-Policy`) بدون `unsafe-inline` أو `unsafe-eval`.
   - `X-Content-Type-Options: nosniff`، `Referrer-Policy: no-referrer`، `Permissions-Policy` بأدنى حد، `frame-ancestors 'none'`، و`COOP/COEP` لخيوط WASM.
   - التأكد من انعدام الموارد الخارجية.
3. **تحديث نموذج التهديدات في ملف `docs/THREAT_MODEL.md`**:
   - توثيق الضوابط الأمنية لـ S1 ضد حقن الصيغ، ملفات الضغط المفخخة، وحماية الأسرار.
4. **الاختبارات الآلية والتحقق**:
   - اختبار تكامل أو وحدات يثبت سلامة الترويسات والسياسات.
5. **التوثيق وتحديث التقارير**:
   - تشغيل الفحص المحلي، تحديث `CHANGELOG.md` وتوثيق تقرير المهمة في `docs/reports/T1.19.md`.
