# خطة تنفيذ المهمة T2.01 — مخطط الوصفة الكامل والترحيل التلقائي

- **معرّف المهمة**: `T2.01`
- **الشريحة**: الشريحة S2: الوصفات والفهم الكامل (أسابيع 5 إلى 8 — القسم 19.8)
- **الفرع**: `task/T2.01-full-recipe-schema`

## 1. الأهداف الرئيسية
1. **إنشاء فرع العمل**: العمل على الفرع `task/T2.01-full-recipe-schema`.
2. **توسيع مخطط الوصفة الرسمي (`recipe.schema.json`) وحزمة `crates/sf-recipe`**:
   - دعم قواعد الأعمدة الكاملة (`column_rules` تشمل `match`, `type`, `meaning_ar`, `code_table`, `is_sensitive`).
   - دعم منطقة الجدول المحددة (`region`).
   - دعم جداول الرموز والمختصرات (`code_table`).
3. **محرك الترحيل التلقائي للإصدارات (`Recipe Migration Engine`)**:
   - قراءة الوصفات ذات الإصدارات القديمة (`schema_version: 0` أو صيغة S1) وترحيلها تلقائيًا للإصدار الحالي (`schema_version: 1`) بأمان تام.
   - إضافة رمز خطأ رسمي `SF-RCP-001` إلى `errors.toml` والمولدات الآلية لمعالجة الأخطاء التالفة أو غير المدعومة.
4. **التحقق بالمخطط من الجهتين واختبارات الحتمية**:
   - التحقق في Rust وTypeScript، وكتابة اختبارات الخصائص ووحدات تثبت صحة الترحيل وثبات محتوى البصمة (`BLAKE3`).
5. **التوثيق وتحديث التقارير**:
   - تشغيل الفحص المحلي `make check`، تحديث `CHANGELOG.md` وتوثيق تقرير المهمة في `docs/reports/T2.01.md`.
