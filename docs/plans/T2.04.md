# خطة تنفيذ المهمة T2.04 — لوحة الفهم الكاملة «اشرح لي هذا العمود» والإعدادات اليدوية

- **معرّف المهمة**: `T2.04`
- **الشريحة**: الشريحة S2: الوصفات والفهم الكامل (أسابيع 5 إلى 8 — القسم 19.8)
- **الفرع**: `task/T2.04-understanding-panel`

## 1. الأهداف الرئيسية
1. **إنشاء فرع العمل**: العمل على الفرع `task/T2.04-understanding-panel`.
2. **حقل الشرح الحر («اشرح لي هذا العمود»)**:
   - تحليل الجمل الشائعة محليًا وتحويلها إلى قواعد منظمة (مثل تحويل «القيمة 0 معناها لم يستلم» إلى قاعدة معالجة الصفر كفراغ/Null، وتحويل «1 ذكر و2 أنثى» إلى جدول رموز Code Table).
3. **تأكيد القواعد قبل التطبيق**:
   - عرض القواعد المستنتجة للمستخدم بصيغة واضحة ليؤكدها أو يعدّلها قبل تطبيقها وحفظها في الوصفة (`SafiRecipe`).
4. **الإعدادات اليدوية وجداول الرموز في لوحة الفهم**:
   - دعم عناصر التحكم اليدوية: جداول الرموز والمختصرات، الوحدة، العملة، صيغة التاريخ والتقويم (ميلادي/هجري)، لغة العمود، علامة «حساس» (Is Sensitive)، المفتاح الأساسي (Primary Key).
5. **الملاحظات وبطاقة الأدلة**:
   - تمكين إضافة ملاحظات على مستوى الملف أو العمود أو الخلية.
   - زر «لماذا؟» لعرض عينات القيم الداعمة للاستنتاج والبدائل المتاحة بنقرة.
6. **اختبارات القبول والتحقق**:
   - كتابة اختبارات وحدات في Vitest تثبت تحويل نص مثل «القيمة 0 معناها لم يستلم» أو «1 ذكر و2 أنثى» إلى قواعد مؤكدة ومقترحة قبل التطبيق.
   - تشغيل البوابة الشاملة وتحديث السجلات والتقارير.
