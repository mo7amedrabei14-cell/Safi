# خطة تنفيذ المهمة T5.04 — كتابة ذرية للملفات، والمجلد المراقَب (F1) بتطبيع المسارات ومنع الروابط الرمزية (القسم 4.10، 18.4)

- **معرّف المهمة**: `T5.04`
- **الشريحة**: الشريحة S5: الديسكتوب والأوفلاين ولوحة المالك (أسابيع 23 إلى 32 — القسم 19.11)
- **الفرع**: `task/T5.04`

## 1. الأهداف الرئيسية
1. **تطوير نظام الكتابة الذرية (Atomic File Writes)**:
   - كتابة الملفات الجديدة عبر ملف مؤقت (`.tmp`) ثم `fsync` ثم إعادة التسمية (`rename`) لضمان عدم تلف الملفات الأصلية أبدًا (البند 13 في `AGENTS.md`).
2. **تطوير المجلد المراقَب (Watched Folder / F1)**:
   - مراقبة مجلد محلي محدد للملفات الجديدة (CSV، XLSX، إلخ).
   - تطبيع المسارات بالكامل ومنع أي محاولة لتجاوز المسار (Path Traversal) أو اتباع الروابط الرمزية (Symlink Protection) وفق القسم 18.4.
3. **التكامل والاختبارات**:
   - إضافة وحدة جديدة `crates/sf-desktop/src/watcher.rs` (أو ضمن `sf-io` / `sf-desktop`) مع اختبارات وحدة شاملة.
   - التحقق من نجاح كافة الاختبارات عبر `cargo test --workspace`.
