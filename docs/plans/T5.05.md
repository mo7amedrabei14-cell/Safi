# خطة تنفيذ المهمة T5.05 — ترخيص الديسكتوب بلا إنترنت: مهلة السماح وتراخيص المؤسسات السنوية وتوقيعات Ed25519 (القسم 9.4 و18.1 ن11)

- **معرّف المهمة**: `T5.05`
- **الشريحة**: الشريحة S5: الديسكتوب والأوفلاين ولوحة المالك (أسابيع 23 إلى 32 — القسم 19.11)
- **الفرع**: `task/T5.05`

## 1. الأهداف الرئيسية
1. **تطوير وحدة الترخيص غير المتصل (`crates/sf-desktop/src/license.rs`)**:
   - التحقق من التراخيص رقميًا باستخدام توقيعات Ed25519 (البند 5 في `AGENTS.md`، القسم 8.3).
   - دعم التراخيص المؤسسية السنوية والتراخيص الشخصية مع مهلة سماح بلا إنترنت (30 يومًا افتراضيًا، وبلا مهلة لترخيص المؤسسات السنوية).
   - كشف التلاعب بساعة النظام (`Clock Rollback Detection`) عبر تتبع الطابع الزمني الأخير.
   - إرجاع حالات الترخيص المحددة: (`Active`, `GracePeriod`, `Expired`, `Invalid`).
   - استخدام رموز الأخطاء المعيارية من `errors.toml` (`SF-AUTH-*` أو رموز ترخيص `SF-LIC-*` المعتمدة).
2. **التكامل والاختبارات**:
   - كتابة اختبارات وحدات شاملة في Rust تغطي:
     - التوقيعات الصحيحة والمزورة أو المتلاعب بمحتواها.
     - التراخيص داخل مهلة الـ 30 يومًا.
     - التراخيص المنتهية بعد مهلة السماح.
     - كشف إرجاع ساعة الجهاز للوراء.
   - التحقق من نجاح كافة الاختبارات عبر `cargo test --workspace`.
