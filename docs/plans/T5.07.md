# خطة تنفيذ المهمة T5.07 — شهادة توقيع ويندوز وتوقيع الملفات (Authenticode / Windows Code Signing & Verification) (القسم 10.2)

- **معرّف المهمة**: `T5.07`
- **الشريحة**: الشريحة S5: الديسكتوب والأوفلاين ولوحة المالك (أسابيع 23 إلى 32 — القسم 19.11)
- **الفرع**: `task/T5.07`

## 1. الأهداف الرئيسية
1. **تطوير وحدة التحقق من التوقيع الرقمي للملفات التنفيذية والمثبّتات (`crates/sf-desktop/src/signing.rs`)**:
   - التحقق من خوارزمية البصمة (`SHA-256`).
   - التحقق من الختم الزمني الموثوق (RFC 3161 Timestamping) وصلاحية شهادة التوقيع.
   - رفض الملفات التنفيذية أو المثبّتات غير الموقّعة أو المتلاعب بها باستخدام رموز الأخطاء المعيارية (`SF-AUTH-001` أو رموز ترخيص `SF-SYS-*`).
2. **التكامل والاختبارات**:
   - كتابة اختبارات وحدات شاملة في Rust تغطي: الملفات الموقّعة توقيعًا سليمًا، المفقود منها الختم الزمني، الموقّعة بشهادة منتهية، والمتلاعب ببصمتها SHA-256.
   - التحقق من نجاح كافة الاختبارات عبر `cargo test --workspace`.
