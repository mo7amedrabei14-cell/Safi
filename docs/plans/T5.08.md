# خطة تنفيذ المهمة T5.08 — المحدّث الموقّع، بيانات الفروقات، منع الرجوع لإصدار أقدم، والرجوع التلقائي عند فشل الإقلاع (القسم 9.8)

- **معرّف المهمة**: `T5.08`
- **الشريحة**: الشريحة S5: الديسكتوب والأوفلاين ولوحة المالك (أسابيع 23 إلى 32 — القسم 19.11)
- **الفرع**: `task/T5.08`

## 1. الأهداف الرئيسية
1. **تطوير وحدة المحدّث الآمن (`crates/sf-desktop/src/updater.rs`)**:
   - التحقق من توقيع تحديثات التطبيق (`Ed25519` Signature Verification).
   - إدارة الفروقات (`Delta Updates`) واستئناف التنزيل.
   - منع الرجوع لإصدار أقدم (`Anti-Downgrade Floor`) بناءً على رقم الإصدار التزايدي الصارم.
   - آلية الإقلاع المشروط والتراجع الآمن (`Pending-Commit Boot Handshake & Rollback Slot`): عزل بيانات المستخدم والخزنة عن الثنائيات، تتبع عداد محاولات الإقلاع، والتراجع التلقائي وفوريًا إلى النسخة السابقة الصالحة عند فشل إقلاع الإصدار الجديد (`Quarantined Builds`) بلا أي فقد في عمل المستخدم أو مسوداته.
   - دعم شاشة «تحديث مطلوب» (`Required Update`) عند وجود حد أدنى إجباري في بيان التحديث.
2. **التكامل والاختبارات**:
   - كتابة اختبارات وحدات وتكامل شاملة في Rust تغطي محاكاة فشل الإقلاع والتراجع التلقائي مع سلامة خزنة المستخدم ومسودة الوصفة.
   - تشغيل اختبارات حزمة سطح المكتب عبر `cargo test -p sf-desktop`.
