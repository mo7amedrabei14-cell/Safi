# خطة تنفيذ المهمة T5.09 — خادم التحديثات وخدمة التوقيع المعزولة (القسم 9.8 و8.4)

- **معرّف المهمة**: `T5.09`
- **الشريحة**: الشريحة S5: الديسكتوب والأوفلاين ولوحة المالك (أسابيع 23 إلى 32 — القسم 19.11)
- **الفرع**: `task/T5.09`

## 1. الأهداف الرئيسية
1. **تطوير خادم التحديثات (Update Server Module in `crates/sf-server`)**:
   - مسارات API لتقديم بيانات الإصدارات الموقّعة (`Signed Manifests`) وحزم الفروقات (`Delta Payloads`) حسب القناة (`stable`, `beta`, `canary`) والإصدار والمنصة.
   - التحقق الصارم من إصدار العميل ومنع الإصدارات المعيبة (`Kill Switch`).
2. **تطوير خدمة التوقيع المعزولة (Isolated Signing Service in `crates/sf-server`)**:
   - عزل مفاتيح التوقيع الخاصة (`Ed25519`) عن مسارات الخادم العام.
   - اشتراط التحقق من بصمات الملفات التنفيذية (`SHA-256 / BLAKE3`) ومصادقة مالك النظام بمفتاح الأمان/البصمة المعتمد.
   - تسجيل كل عملية توقيع في سجل التدقيق المعياري (`Audit Log`) لا يقبل التعديل.
3. **الاختبارات والتكامل**:
   - كتابة اختبارات وحدات وتكامل في Rust تغطي: تقديم التحديثات، رفض التوقيع بلا مصادقة المالك، وعزل مفاتيح التوقيع.
   - تشغيل الفحص الشامل `cargo test --workspace`.
