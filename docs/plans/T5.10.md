# خطة تنفيذ المهمة T5.10 — محرك كشف وحماية البيانات الشخصية الحساسة (PII Detection & Protection) (القسم 8.2، 8.9)

- **معرّف المهمة**: `T5.10`
- **الشريحة**: الشريحة S5: الديسكتوب والأوفلاين ولوحة المالك (أسابيع 23 إلى 32 — القسم 19.11)
- **الفرع**: `task/T5.10`

## 1. الأهداف الرئيسية
1. **تطوير محرك PII (`crates/sf-core/src/pii.rs` أو حزمة جديدة/قائمة)**:
   - كشف الأنماط الحساسة المحلية والدولية: الرقم القومي المصري (14 رقمًا)، أرقام الهواتف المصرية والدولية، البريد الإلكتروني، الحسابات البنكية (IBAN)، وأرقام البطاقات الائتمانية.
   - تطبيق العمليات الأربع بدقة تامة وبصفر اعتماديات شبكة:
     أ) **الإخفاء (Masking / Redaction)**: إخفاء الأجزاء الحساسة مع الحفاظ على اتجاه النص العربي (`RTL`).
     ب) **التشفير العكسي الآمن (Reversible Encryption)**: تشفير الخلية بمفتاح محلي مشتق بحيث لا يمكن استعادتها إلا بامتلاك المفتاح الصحيح.
     ج) **الاستبدال الرمزي الحتمي (Deterministic Tokenization)**: توليد رمز حتمي (`token`) ثابت لنفس القيمة الحساسة عبر الجداول والسجلات لتمكين التحليل الإحصائي دون كشف الهوية.
     د) **التصنيف والتنبيه**: إطلاق رموز الأخطاء والتشخيص المعيارية (`errors.toml`).
2. **الاختبارات والتكامل**:
   - كتابة اختبارات وحدة شاملة تغطي كشف PII العربي والإنجليزي، الإخفاء، التشفير العكسي، والثبات الرمزي.
   - التحقق من تكامل الكود مع بنية المشروع عبر `cargo test --workspace`.
