# خطة تنفيذ المهمة T5.13 — مركز السجلات في لوحة المالك (Log Center & Audit Trail Explorer) (القسم 9.6، 9.8)

- **معرّف المهمة**: `T5.13`
- **الشريحة**: الشريحة S5: الديسكتوب والأوفلاين ولوحة المالك (القسم 19.11)
- **الفرع**: `task/T5.13`

## 1. الأهداف الرئيسية
1. **تطوير نظام مركز السجلات في `crates/sf-server`**:
   - توفير مسار API `/v1/owner/audit-logs` محمي خلف حارس `ZeroTrustGuard` ومفاتيح الأمان.
   - دعم التصفية المتقدمة حسب مستوى الخطورة، رموز الأخطاء المعيارية (`SF-*`)، نطاق التاريخ، ونوع الأحداث الإدارية.
   - التحقق الصارم من سلامة سلسلة بصمات `BLAKE3` لسجل التدقيق (`audit_log`) لكشف أي تلاعب أو تعديل غير مرخص.
   - ضمان حجب كامل وتصفية (`Redaction`) لأي معلومات شخصية حساسة أو أسرار (`PII / Secrets`).
2. **تطوير واجهة مركز السجلات في الواجهة الأمامية (`apps/web`)**:
   - بناء مكون `LogCenter.tsx` داخل لوحة المالك مع دعم التصفية الفورية، عرض بصمات الـ Hash وسلسلة التدقيق، وتصدير السجلات الموقّعة.
   - الالتزام بمعايير الاتاحة (`WCAG 2.2 AA`)، ودعم اللغة العربية (`RTL`) الكامل، وتصميم `I-Have-ADHD` غير المشتت.
3. **الاختبارات والتكامل**:
   - كتابة اختبارات وحدات وتكامل شاملة في Rust و `Vitest` للتحقق من استعلام السجلات وسلامة السلسلة وخلوها من الأسرار، واجتياز `make check`.
