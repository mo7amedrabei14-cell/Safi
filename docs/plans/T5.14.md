# خطة تنفيذ المهمة T5.14 — تطبيق المالك PWA للموبايل وإشعارات الطوارئ (القسم 9.6، 9.8)

- **معرّف المهمة**: `T5.14`
- **الشريحة**: الشريحة S5: الديسكتوب والأوفلاين ولوحة المالك (القسم 19.11)
- **الفرع**: `task/T5.14`

## 1. الأهداف الرئيسية
1. **تطوير تطبيق المالك PWA للموبايل (`Owner Mobile PWA`)**:
   - إعداد ملف بيان التطبيق المخصص للوحة المالك (`apps/web/public/owner-manifest.webmanifest`) بدعم كامل للغة العربية (`RTL`) ووضع العرض المستقل (`standalone`) والأيقونات المخصصة.
   - تطوير عامل الخدمة الآمن (`apps/web/public/owner-sw.js`) مع سياسة تخزين صارمة تمنع تخزين أي بيانات حساسة أو سجلات تدقيق أو رموز مصادقة في ذاكرة التخزين المؤقت غير المشفّرة.
2. **تحسين واجهة الموبايل والوصول السريع للطوارئ**:
   - تكييف مكونات لوحة المالك لتكون متجاوبة بالكامل مع شاشات الهواتف المحمولة وفق معايير `I-Have-ADHD` و`WCAG 2.2 AA` (أهداف لمس $\ge 44\times44\text{px}$، الوصول بضغطة واحدة لأزرار وضع الصيانة الطارئ وإيقاف الإصدارات المعيبة، ودعم Passkeys).
   - محاكاة إشعارات الطوارئ الفورية (`Emergency Push Notifications`).
3. **الاختبارات والتكامل**:
   - كتابة اختبارات شاملة في `Vitest` للتحقق من إعدادات بيان PWA وسياسة عامل الخدمة، واجتياز البوابة الشاملة `make check`.
