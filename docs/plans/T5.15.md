# خطة تنفيذ المهمة T5.15 — أداة سطر الأوامر `safi` (CLI) (القسم 10.6)

- **معرّف المهمة**: `T5.15`
- **الشريحة**: الشريحة S5: الديسكتوب والأوفلاين ولوحة المالك (القسم 19.11)
- **الفرع**: `task/T5.15`

## 1. الأهداف الرئيسية
1. **تطوير أداة سطر الأوامر `safi` (CLI)**:
   - بناء البرنامج التنفيذي `safi` ضمن حزمة `crates/sf-cli` أو وحدة ضمن مسار المشروع لتنفيذ الأوامر الفرعية المعتمدة:
     - `safi clean <file> --recipe <recipe> --out <output>` (تنضيف البيانات وتطبيق الوصفات).
     - `safi profile <file>` (استخراج سمات الأعمدة وأنواعها وثقتها).
     - `safi report <file>` (توليد تقرير جودة البيانات).
     - `safi recipe apply <file> --recipe <recipe>` (تطبيق وصفة التغييرات بايتًا ببايت).
2. **الضوابط الأمنية ومعايير المحرك**:
   - صفر اعتماديات شبكة مطلقًا (`AGENTS.md` Rule #7).
   - الكتابة الذرية للمخرجات (ملف مؤقت -> `fsync` -> إعادة تسمية) بحيث لا يتم المساس بالملف الأصلي أبدًا.
   - التحقق من ترخيص الديسكتوب بلا إنترنت (`Ed25519`).
   - إرجاع رموز خروج قياسية (`Exit Codes: 0` للنجاح، `1-3` للأخطاء التشغيلية أو الأمنية) مع رموز أخطاء `errors.toml` ودعم خروج مهيكل بصيغة `JSON` أو نصوص عربية مبسطة.
3. **الاختبارات والتكامل**:
   - كتابة اختبارات وحدة وتكامل شاملة في Rust تغطي الأوامر الفرعية ومعالجة الملفات والمدخلات الخاطئة والكتابة الذرية، واجتياز `make check`.
