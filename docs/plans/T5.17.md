# خطة تنفيذ المهمة T5.17 — اختبار المنصات والدقة العالية (Cross-Platform & High-DPI Verification) (القسم 18.6، 20)

- **معرّف المهمة**: `T5.17`
- **الشريحة**: الشريحة S5: الديسكتوب والأوفلاين ولوحة المالك (القسم 19.11)
- **الفرع**: `task/T5.17`

## 1. الأهداف الرئيسية
1. **توافق المنصات المتعددة (Windows / Linux / macOS)**:
   - التحقق من معالجة مسارات الملفات (`/` مقابل `\`)، فواصل الأسطر (`CRLF` و`LF`)، والأذونات عبر منصات التشغيل المختلفة.
   - التحقق من توافق إعدادات نافذة Tauri 2.2 في `tauri.conf.json` وأمان CSP الصارم بلا شبكة.
2. **دعم الشاشات ذات الكثافة والدقة العالية (`High-DPI / Display Scaling`)**:
   - اختبار معاملات التكبير (`100%`, `125%`, `150%`, `200%`) في الغلاف والواجهة (`apps/web` و`sf-desktop`).
   - ضمان عدم انكسار تخطيط العربية `RTL`، أو اقتصاص الحروف المتصلة العربية، أو تشوه الرسوم البيانية (`SVG / Canvas`) عند التكبير.
3. **سهولة الوصول ومعايير WCAG 2.2 AA**:
   - استيفاء معايير التباين، أحجام أهداف اللمس والمؤشر، وتكامل الأزرار والعناصر عبر جميع معاملات الدقة والتكبير.
4. **الاختبارات والتوثيق**:
   - كتابة اختبارات وحدات وتكامل في Rust (`sf-desktop`) و`Vitest` (`apps/web`).
   - تشغيل `make check` كاملًا، تحديث `CHANGELOG.md`، وكتابة تقرير المخرجات.
