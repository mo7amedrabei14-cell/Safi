# تقرير إنجاز المهمة `T1.02` — الأنواع الأساسية لمحرك البيانات ونموذج الأخطاء (`crates/sf-core`)

---

## 1. ما الذي أُنجز (في 3 أسطر)
1. **دمج `T1.01` في `main` وبناء هياكل الجدول والورقة والعمود والخلية والقيمة في `crates/sf-core`**: تنفيذ هياكل `Table` و`Sheet` و`Column` و`ColumnSchema` و`CellValue` و`Value` مع حفظ النص الأصلي (`raw_text`) دائمًا بجانب القيمة الموحّدة والمهيكلة وفق القسم 4.4، ومعاملة رموز الفراغ (`-`، `N/A`، `لا يوجد`، `غير متوفر`) كفراغ مع بقاء نصها الأصلي محفوظًا وفق القسم 4.7.
2. **دعم الدقة المالية العشرية وحفظ الأصفار البادئة وتعداد الأعمدة ودرجة الثقة**: اعتماد `rust_decimal::Decimal` (بلا `float`) للمبالغ المالية والنسب والقياسات (`MoneyValue` و`Value`)، وحفظ المعرّفات والأرقام القومية والهواتف كنصوص لا تُحذف أصفارها البادئة أبدًا (`ZeroPreservedText`)، وتعريف تعداد `ColumnType` (الأنواع الـ 12 في القسم 4.3 + `Unknown` «غير معروف») وهيكل `ConfidenceScore` بالعتبتين القياسيتين (`0.8` للتطبيق التلقائي و`0.5` لسؤال المستخدم).
3. **بناء هيكل الخطأ والسجل الآمن الخالي من بيانات المستخدم وثوابت حدود المنصات واخضرار `GitHub Actions`**: تنفيذ `SafiError` و`ErrorCode` (`SF-<DOMAIN>-<NNN>`) و`ErrorDomain` (المجالات الـ 15) و`ErrorSeverity` و`SafeEngineLogRecord` بصيغة JSON خالية تمامًا من قيم الخلايا أو أسماء الملفات أو أسماء الأعمدة (القسمان 15.1 و15.3)، وتعريف ثوابت حدود المنصات (الويب `250MB` / `500` ألف صف، والديسكتوب/CLI `10GB` / `10` ملايين صف وفق القسم 20.4) واجتياز `make check` و`GitHub Actions`.

## 2. كيف تجرّبه بنفسك (خطوات مرقّمة بسيطة جدًا)
1. تأكد من وجودك على فرع المهمة:
   ```bash
   git status -sb
   ```
2. شغّل اختبارات الوحدات الشاملة لحزمة `sf-core`:
   ```bash
   cargo test -p sf-core
   ```
3. شغّل فحص انعدام الشبكة داخل محرك Rust (مع الاختبار الذاتي السلبي):
   ```bash
   bash tools/check-no-network.sh && bash tools/check-no-network.sh --self-test
   ```
4. شغّل البوابة الشاملة للمشروع بالكامل:
   ```bash
   make check
   ```
5. لمشاهدة نتائج `GitHub Actions CI` الفعلية الخضراء على مستودعك:
   - دمج `T1.01` في `main`: `https://github.com/mo7amedrabei14-cell/Safi/actions/runs/41362909970` (`conclusion=success`)
   - فرع `task/T1.02-sf-core-types`: `https://github.com/mo7amedrabei14-cell/Safi/actions/runs/41364450199` (`conclusion=success`)

## 3. ما الذي فشل أو لم يكتمل (بصراحة)
- **لا يوجد أي بند غير مكتمل في نطاق `T1.02`**:
  - أثناء أول تشغيل لـ `GitHub Actions` على `ubuntu-latest` بعد إضافة `rust_decimal`، تجاوز حجم مخرج `cargo metadata` المتغير البيئي `METADATA_JSON` حد نواة لينكس للمتغير الواحد (`MAX_ARG_STRLEN = 128KB`) داخل `tools/check-no-network.sh`. تم إصلاحه فورًا بقراءة `cargo metadata` عبر أنبوب مباشر (`subprocess.check_output`) بدل المتغير البيئي، واخضرّت البوابة على `ubuntu-latest` و`windows-latest` معًا.
  - التزامًا صارمًا بحدود النطاق: لم يُكتب سكربت التوليد الآلي من `errors.toml` (المهمة `T1.03`)، ولم تُمسّ حزم `sf-io` أو `sf-arabic` أو `sf-profile`.
