# تقرير إنجاز المهمة `T1.03` — توليد أكواد الأخطاء ومفاتيح الترجمة آليًا من `errors.toml` والفحص الصارم (`crates/sf-core`, `packages/i18n`)

---

## 1. ما الذي أُنجز (في 3 أسطر)
1. **استكمال مصدر الحقيقة الوحيد لرموز الأخطاء (`errors.toml`)**: تحديث ملف `errors.toml` في جذر المستودع ليضم جميع رموز الأخطاء المستخدمة في النواة مع الشدة والعنوان والإجراء المقترح باللغتين العربية والإنجليزية وملاحظة المالك التقنية.
2. **بناء أداة التوليد والفحص الحتمية (`tools/gen-errors.py`)**: تنفيذ أداة ذكية تولّد آليًا كود Rust في `crates/sf-core/src/generated_errors.rs` وكود TypeScript ومفاتيح الترجمة وقواميس الأخطاء الثنائية في `packages/i18n/src/generated-errors.ts` مع فحص CI صارم يمنع أي خطأ بلا رمز ويشمل اختبارًا ذاتيًا سلبيًا (`--self-test`).
3. **تكامل النواة وحزمة الترجمة واجتياز الفحوص**: ربط الكود المولّد بـ `crates/sf-core` و`packages/i18n` مع اختبارات وحدات شاملة، وإضافة بوابة الفحص لـ `Makefile` (`make check`) وتحديث `CHANGELOG.md`.

---

## 2. كيف تجرّبه بنفسك (خطوات مرقّمة بسيطة جدًا)
1. تأكد من وجودك على فرع المهمة:
   ```bash
   git status -sb
   ```
2. شغّل أداة التوليد للتأكد من تطابق الملفات:
   ```bash
   py -3 tools/gen-errors.py --generate
   ```
3. شغّل فحص CI الصارم والاختبار الذاتي السلبي للأخطاء:
   ```bash
   py -3 tools/gen-errors.py --check && py -3 tools/gen-errors.py --self-test
   ```
4. شغّل اختبارات الوحدات لـ `sf-core` و`i18n`:
   ```bash
   cargo test -p sf-core
   pnpm --filter @safi/i18n run test
   ```
5. شغّل البوابة الشاملة للمشروع بالكامل:
   ```bash
   make check
   ```
