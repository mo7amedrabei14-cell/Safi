# تقرير إنجاز المهمة `T1.04` — محرك استيراد CSV بالبث والكشف التلقائي للترميز والفاصل (`crates/sf-io`)

---

## 1. ما الذي أُنجز (في 3 أسطر)
1. **بناء حزمة استيراد CSV بالبث داخل `crates/sf-io`**: تنفيذ قارئ CSV وTSV وTXT المفصول بالدفعات (`chunks`) لمعالجة الملفات الكبيرة بكفاءة ذاكرة عالية استنادًا إلى القسم 4.2.
2. **الكشف التلقائي الدقيق للترميز والفاصل**: دعم كامل لترميز `UTF-8` (مع أو بدون BOM) و`Windows-1256` عبر `chardetng` و`encoding_rs` مع إطلاق رمز الخطأ المعتمد `SF-IMP-002` عند انخفاض الثقة، وكشف الفاصل آليًا (`comma`, `semicolon`, `tab`).
3. **فرض حدود الحجم للمنصة وتكامل النواة**: تطبيق قيود المنصة (`PlatformLimits`) وإطلاق الخطأ القياسي `SF-IMP-003` عند تجاوز الحد المسموح، مع حفظ خلايا الملف بدقة داخل هياكل `sf-core` (`Table`, `Column`, `CellValue`, `ZeroPreservedText`) بحتمية تامة وصفر اعتماديات شبكة.

---

## 2. كيف تجرّبه بنفسك (خطوات مرقّمة بسيطة جدًا)
1. تأكد من وجودك على فرع المهمة:
   ```bash
   git status -sb
   ```
2. شغّل اختبارات الوحدات الشاملة لحزمة `sf-io`:
   ```bash
   cargo test -p sf-io
   ```
3. شغّل فحص انعدام الشبكة داخل محرك Rust (مع الاختبار الذاتي السلبي):
   ```bash
   bash tools/check-no-network.sh && bash tools/check-no-network.sh --self-test
   ```
4. شغّل البوابة الشاملة للمشروع بالكامل:
   ```bash
   make check
   ```

---
