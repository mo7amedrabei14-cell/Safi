# تقرير إنجاز المهمة `T1.05` — قارئ Excel وODS بالبث مع فك الخلايا المدمجة وضد هجمات ضغط الملفات المفخخة (`SF-IMP-005`) في `crates/sf-io`

---

## 1. ما الذي أُنجز (في 3 أسطر)
1. **توسيع حزمة `crates/sf-io` لدعم قارئ جداول Excel وODS (`XLSX`, `XLS`, `ODS`, `XLSM`)** القائم على مكتبة `calamine` الآمنة لاستخراج الأوراق المتعددة وكشف صفوف الترويسة بدقة تامة.
2. **فك الخلايا المدمجة (`Merged Cells Unmerging`)**: تكرار قيمة الخلية المدمجة الأساسية عبر نطاق الجدول لضمان سلامة العمليات الحسابية والفرز وعدم ترك خلايا فارغة.
3. **الدفاع الصارم ضد ملفات الضغط المفخخة (`Zip Bombs` — `SF-IMP-005`)**: فحص نسبة فك الضغط (أقصى نسبة $100$) والحجم الإجمالي غير المضغوط (أقصى حد $500\text{ MB}$) ورفض الملفات المشبوهة فورًا برمز الخطأ المعتمد `SF-IMP-005`، مع تطبيق قيود السعة والصفوف `SF-IMP-003` وصفر اعتماديات شبكة.

---

## 2. كيف تجرّبه بنفسك (خطوات مرقّمة بسيطة جدًا)
1. تأكد من وجودك على فرع المهمة:
   ```bash
   git status -sb
   ```
2. شغّل اختبارات الوحدات لـ `sf-io`:
   ```bash
   cargo test -p sf-io
   ```
3. شغّل فحص انعدام الشبكة لمحرك Rust (مع الاختبار الذاتي السلبي):
   ```bash
   bash tools/check-no-network.sh && bash tools/check-no-network.sh --self-test
   ```
4. شغّل البوابة الشاملة للمشروع بالكامل:
   ```bash
   make check
   ```
