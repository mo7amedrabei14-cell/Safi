# تقرير إنجاز المهمة `T1.06` — حزمة التطبيع والتنضيف العربي (`sf-arabic`)

---

## 1. ما الذي أُنجز (في 3 أسطر)
1. **بناء حزمة التطبيع والتنضيف العربي (`crates/sf-arabic`) وفق القسم 4.4 من المواصفة**: تنفيذ محرك تطبيع يدعم توحيد أشكال الألف (`أ`, `إ`, `آ`, `ٱ` إلى `ا`)، وتوحيد الياء (`ى` إلى `ي`) والتاء المربوطة (`ة` إلى `ه`)، مع الحفاظ الدائم على النص الأصلي للمستخدم واستخدام النسخة الموحّدة للمطابقة فقط.
2. **إزالة التطويل والتشكيل والتحكم**: إزالة الكشيدة (`ـ`) وكافة حركات التشكيل العربية ومسافات `NBSP` والأحرف غير المرئية وعلامات الاتجاه (`ZWJ`, `ZWNJ`, `RLM`, `LRM`) بدون المساس بالترتيب المنطقي للحروف.
3. **تطبيع الأرقام وضم الأسماء المركبة واختبارات الخصائص (`proptest`)**: تحويل الأرقام المشرقية/الهندية إلى لاتينية، وضم الأسماء المركبة («عبد»، «أبو»، «أم» مع ما يليها)، وكتابة اختبارات خصائص شاملة تثبت خاصية الثبات (`Idempotence`): `normalize(normalize(s)) == normalize(s)`.

---

## 2. كيف تجرّبه بنفسك (خطوات مرقّمة بسيطة جدًا)
1. تأكد من وجودك على فرع المهمة:
   ```bash
   git status -sb
   ```
2. شغّل اختبارات الوحدات واختبارات الخصائص لـ `sf-arabic`:
   ```bash
   cargo test -p sf-arabic
   ```
3. شغّل فحص انعدام الشبكة لمحرك Rust (مع الاختبار الذاتي السلبي):
   ```bash
   bash tools/check-no-network.sh && bash tools/check-no-network.sh --self-test
   ```
4. شغّل اختبارات المشروع بالكامل:
   ```bash
   cargo test --workspace
   ```
