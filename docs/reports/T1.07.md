# تقرير إنجاز المهمة `T1.07` — محرك تعرّف وفهم أنواع الأعمدة (`crates/sf-profile`)

---

## 1. ما الذي أُنجز (في 3 أسطر)
1. **بناء محرك ترويس وستنتاج أنواع الأعمدة (`crates/sf-profile`) وفق القسمين 4.3 و16.1**: فحص العينات حتى 10 آلاف قيمة لكل عمود بالاعتماد على حزمة التنضيف العربي `sf-arabic` وقاموس مرادفات العناوين باللغتين العربية والانجليزية.
2. **عقد الفهم وتطبيق العتبات الصارمة**: إرجاع درجة الثقة (`0.0` إلى `1.0`) والأدلة (عينات القيم والأنماط) والبدائل المحتملة، مع تطبيق عتبة `0.8` (تلقائي في المعاينة) وعتبة `0.5` (سؤال المستخدم)، وتصنيف الأعمدة دون `0.5` كـ `Unknown` وفق عقد الفهم.
3. **حماية المعرّفات وبناء المجموعة الذهبية**: تمييز أعمدة المعرّفات والأرقام القومية والهواتف لضمان حفظها كنصوص دائمًا دون فقدان الأصفار البادئة، وبناء مجموعة اختبار ذهبية لقياس دقة التعرّف آليًا.

## 2. كيف تجرّبه بنفسك (خطوات مرقّمة بسيطة جدًا)
1. تأكد من وجودك على فرع المهمة:
   ```bash
   git status -sb
   ```
2. شغّل اختبارات الوحدات لـ `sf-profile`:
   ```bash
   cargo test -p sf-profile
   ```
3. شغّل فحص انعدام الشبكة لمحرك Rust (مع الاختبار الذاتي السلبي):
   ```bash
   bash tools/check-no-network.sh && bash tools/check-no-network.sh --self-test
   ```
4. شغّل اختبارات المشروع بالكامل:
   ```bash
   cargo test --workspace
   ```
