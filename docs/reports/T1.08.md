# تقرير إنجاز المهمة `T1.08` — محرك العمليات الخمس للتنضيف والتراجع بالفروقات (`crates/sf-clean`)

---

## 1. ما الذي أُنجز (في 3 أسطر)
1. **تطوير محرك العمليات الخمس للتنضيف والتراجع (`crates/sf-clean`) وفق الأقسام 4.5، 4.6، 4.7، و4.10**: تنفيذ عمليات توحيد النص العربي، حذف المكرر الدقيق وبعد التوحيد، معالجة الفراغات وقواعد منع ملء أعمدة الهوية، توحيد التواريخ مع كشف الغموض وإطلاق الخطأ `SF-CLN-001` دون حسم صامت، وتوحيد الأرقام والعملات والهواتف.
2. **سجل الفروقات والتراجع التام (`Deltas & Undo`)**: تسجيل كل عملية ببطاقة تتبع عدد الخلايا المتأثرة وعينة قبل/بعد، وتخزين التراجع كفروقات (`deltas`) دقيقة تعيد الجدول إلى حالته الأصلية بايتًا ببايت دون مساس بالأصل.
3. **اختبارات الوحدة وخصائص التراجع**: ضمان سلامة العمليات وتوثيق التوافق التام مع متطلبات الشريحة الأولى وسجل التاريخ.

---

## 2. كيف تجرّبه بنفسك (خطوات مرقّمة بسيطة جدًا)
1. تأكد من وجودك على فرع المهمة:
   ```bash
   git status -sb
   ```
2. شغّل اختبارات الوحدات لـ `sf-clean`:
   ```bash
   cargo test -p sf-clean
   ```
3. شغّل فحص انعدام الشبكة لمحرك Rust (مع الاختبار الذاتي السلبي):
   ```bash
   bash tools/check-no-network.sh && bash tools/check-no-network.sh --self-test
   ```
4. شغّل اختبارات المشروع بالكامل:
   ```bash
   cargo test --workspace
   ```
