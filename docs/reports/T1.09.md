# تقرير إنجاز المهمة `T1.09` — مخطط الوصفة والخطوات وبصمة المحتوى الحتمية (`crates/sf-recipe`)

---

## 1. ما الذي أُنجز (في 3 أسطر)
1. **بناء هياكل الوصفة والخطوات (`crates/sf-recipe`) وفق القسمين 4.9 و19.5**: تمثيل `SafiRecipe` ومخطط العمليات التسع المعتمدة في `RecipeOperation` بما يتطابق تمامًا مع `recipe.schema.json`.
2. **بصمة المحتوى الحتمية المستقلة (`content_hash`)**: تطبيق حساب بصمة المحتوى الحتمية باستخدام تجزئة `BLAKE3` المعيارية وبصيغة JSON معيارية مستقلة عن ترتيب المفاتيح لضمان التطابق بايتًا ببايت (`AGENTS.md` Rule #12).
3. **التحقق والاختبارات**: التحقق من إصدار المخطط (`schema_version = 1`) وتوفير اختبارات الوحدات الشاملة لضمان سلامة التسلسل والتحويل وصفر اعتماديات شبكة.

---

## 2. كيف تجرّبه بنفسك (خطوات مرقّمة بسيطة جدًا)
1. تأكد من وجودك على فرع المهمة:
   ```bash
   git status -sb
   ```
2. شغّل اختبارات الوحدات لـ `sf-recipe`:
   ```bash
   cargo test -p sf-recipe
   ```
3. شغّل فحص انعدام الشبكة لمحرك Rust (مع الاختبار الذاتي السلبي):
   ```bash
   bash tools/check-no-network.sh && bash tools/check-no-network.sh --self-test
   ```
4. شغّل اختبارات المشروع بالكامل:
   ```bash
   cargo test --workspace
   ```
