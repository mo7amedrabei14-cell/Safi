# تقرير إنجاز المهمة `T1.12` — حزمة التدويل والتدقيق اللغوي (`packages/i18n`)

---

## 1. ما الذي أُنجز (في 3 أسطر)
1. **بناء محرك التدويل بصيغة ICU وقواميس العربية والإنجليزية**: دعم القواميس الكاملة `ar.json` (اللغة الافتراضية الأولى) و `en.json` باصطلاح مفاتيح `area.component.element` وتغطية الشاشة الرئيسية والتنظيف والفهم والتصدير والأخطاء المולدة.
2. **توفير مزوّد React (`I18nProvider` و `useI18n`)**: تبديل لغة الواجهة واتجاه الصفحة (`dir="rtl"`, `dir="ltr"`, `lang`) فورًا في الذاكرة دون إعادة تحميل للصفحة، مع دالة اختبار تمديد النصوص بنسبة 40%.
3. **سكربت فحص القواميس الآلي في CI (`verify-i18n.py`)**: ربط الفحص ببوابة `make check` لضمان تطابق المفاتيح وعدم وجود قيم فارغة أو اختلاف في متغيرات ICU.

---

## 2. كيف تجرّبه بنفسك (خطوات مرقّمة بسيطة جدًا)
1. تأكد من وجودك على فرع المهمة:
   ```bash
   git status -sb
   ```
2. شغّل سكربت فحص القواميس مع الاختبار الذاتي السلبي:
   ```bash
   python3 tools/verify-i18n.py && python3 tools/verify-i18n.py --self-test
   ```
3. شغّل اختبارات الوحدات لـ i18n عبر Vitest:
   ```bash
   pnpm run test
   ```
4. شغّل بوابة الفحص الشاملة:
   ```bash
   make check
   ```
