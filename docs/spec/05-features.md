## 5. كتالوج الميزات الكامل

كل ميزة لها رقم ومعيار قبول قابل للاختبار، ولكل رقم اختبار آلي إلزامي. كل ما يلي ضمن الإصدار $1.0$ إلا ما كُتب بجانبه ($1.1$) أو ($1.2$).

### أ. الاستيراد والتصدير

| الرقم | الميزة | معيار القبول | 
| ----- | ----- | ----- |

| A2 | «فتح بواسطة صافي» من مدير الملفات (ديسكتوب) | الامتدادات `xlsx` و`csv` و`xls` تظهر كخيار فتح |

| A8 | تصدير CSV وJSON وParquet | UTF-8 مع BOM أو بدونه اختيارًا | 
| A9 | تصدير جاهز لـ Power BI | ملف بأنواع صحيحة وجدول تواريخ مرفق | 
| A10 | تصدير PDF وPNG للتقارير | هوية قابلة للتخصيص | 
| A11 | حماية CSV Injection | أي خلية تبدأ بـ `=` أو `+` أو `-` أو `@` تُحمى عند التصدير، والخيار مفعّل افتراضيًا |
