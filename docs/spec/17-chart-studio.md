## 17. محرر الرسوم البيانية (Chart Studio)

هدف المحرر: من جدول نظيف إلى رسم صالح للنشر في دقيقة، بتحكم كامل في الشكل واللون، وبحماية المستخدم من الرسوم المضللة. وهو يُفتح من أي ملف أو تقرير أو لوحة، ويشترك في الهوية والثيمات مع بقية المنتج.

### 17.1 أنواع الرسوم (أكثر من 30)

| العائلة | الأنواع | 
| ----- | ----- | 
| المقارنة | أعمدة وأشرطة (عادية، مجمّعة، مكدّسة، مكدّسة $100\%$)، `lollipop`، `dumbbell` لفرق نقطتين | 
| الزمن | خط، مساحة (عادية ومكدّسة)، خطوة (`step`)، خريطة حرارة تقويمية، `sparkline` | 
| الجزء من الكل | دائري وحلقي، خريطة شجرية (`treemap`)، `sunburst`، `waffle` | 
| التوزيع | مدرج تكراري، صندوقي (`box`)، كمان (`violin`)، كثافة | 
| العلاقة | انتشار، فقاعات، خريطة حرارة لمصفوفة الارتباط | 
| التدفق والعملية | قمع (`funnel`)، شلال (`waterfall`)، `Sankey`، باريتو | 
| المؤشرات | بطاقة KPI، مقياس (`gauge`)، رصاصة (`bullet`)، رادار | 
| مركّبة | أعمدة + خط بمحورين، رسوم صغيرة متعددة (`small multiples`) | 
| الجغرافيا | خريطة ملوّنة بمحافظات مصر وبدول العالم. بيانات الحدود من مصدر مفتوح يتحقق الوكيل من ترخيصه | 
| الجداول المرئية | جدول بألوان مشروطة وأشرطة بيانات وأيقونات | 

### 17.2 الإنشاء الذكي

* يقترح المحرر ثلاثة رسوم مناسبة لأنواع الأعمدة (زمن $\leftarrow$ خط، فئة $\leftarrow$ أعمدة، جزء من كل $\leftarrow$ مكدّس أو حلقي، علاقة $\leftarrow$ انتشار)، وتحت كل منها جملة «لماذا هذا الرسم؟».

* إنشاء بجملة بأي لغة: «ارسم مبيعات كل شهر حسب الفرع بأعمدة مكدسة بألوان هويتنا». الذكاء الاصطناعي يولّد مواصفة رسم (JSON) فقط، ويرسمها المحرك بكود حتمي، ثم تعدّلها بصريًا. الذكاء لا يولّد أرقامًا أبدًا.

* تبديل نوع الرسم بنقرة مع معاينة حية، وتبقى الألوان والعناوين والإعدادات المشتركة.

### 17.3 التحكم في الشكل

* **الأبعاد:** شريحة $16:9$، A4 عمودي وأفقي، مربع $1:1$ للتواصل، قصة $9:16$، أو مقاس مخصص، مع الهوامش والخلفية والزوايا.

* **الأشكال:** سمك الخطوط، خطوط ملساء أو مستقيمة، شكل النقاط، عرض الأعمدة والمسافات، وحجم ثقب الحلقي وزاوية البداية.

* **الاتجاه:** يتبع لغة المستخدم، وفي العربية يتدرج المحور الأفقي من اليمين لليسار ويقع المحور الرأسي على اليمين، وكله قابل للتعديل.

* **الفئات:** ترتيب يدوي أو بالقيمة أو أبجدي بحسب قواعد اللغة، وأعلى $N$ مع تجميع الباقي في «أخرى».

* **المحاور والشبكة:** خطي أو لوغاريتمي، مدى، عكس، وخطوط شبكة.

* **التسميات:** قيم ونسب وأسماء، بتنسيق أرقام وتواريخ وتقاويم حسب اللغة.

* **العناوين والمصدر:** عنوان وعنوان فرعي ومصدر وحاشية، ووسيلة إيضاح بموضع وترتيب.

* **الشروحات:** خط مرجعي (هدف أو متوسط)، منطقة مظللة، سهم مع ملاحظة، إبراز نقطة.

* **التفاعل:** تلميحات وتحديد وتصفية وتعمّق (`drill-down`) وتقريب.

### 17.4 الألوان

* **مكتبة لوحات:** فئوية متباعدة، متدرجة للقيم المتصلة، متباعدة حول نقطة وسط (ربح وخسارة)، آمنة لعمى الألوان، أحادية اللون، رمادية آمنة للطباعة، ولوحات الهوية.

* لون لكل سلسلة أو شريحة أو نقطة بمنتقي ألوان مع إدخال HEX وRGB وHSL وقطّارة، مع التدرج والشفافية.

* تلوين مشروط بالقيمة بقواعد بصرية: «أحمر إن أقل من الهدف وأخضر إن بلغه».

* **مدقق التباين:** تنبيه إن قلّ تباين عناصر الرسم عن $3:1$ أو النص عن $4.5:1$ بحسب WCAG.

* أنماط وأشكال إضافية (خطوط مائلة، نقاط، علامات مختلفة) حتى لا يعتمد الفهم على اللون وحده.

* **ثيمات:** فاتح، داكن، عرض تقديمي، تقرير مطبوع، وثيمة هوية الجهة (D7) تُطبَّق على كل رسوم الفريق بنقرة. يتحول الرسم بين الفاتح والداكن تلقائيًا.

* **فرشاة الأنماط:** انسخ نمط رسم وطبّقه على آخر، واحفظ لوحاتك وثيماتك في مساحة العمل.

* الخط لكل لغة بحسب 6.3 و14.2.

### 17.5 حارس المصداقية

يمنع المحرر الرسم المضلل افتراضيًا. الحارس يحذّر ويقترح ولا يمنع، والقرار للمستخدم.

| الحالة | ما يحدث | 
| ----- | ----- | 
| محور الأعمدة لا يبدأ من الصفر | تحذير مع إصلاح بنقرة (الأعمدة تبدأ من الصفر افتراضيًا) | 
| دائري بأكثر من $6$ شرائح | اقتراح الأعمدة | 
| محوران بمقياسين مختلفين | تحذير ووسم واضح لكل محور | 
| مقياس لوغاريتمي | وسم صريح على المحور | 
| رسوم متجاورة بمقاييس مختلفة | اقتراح توحيد المقياس | 
| بيانات ناقصة | تُعرض كفجوة أو علامة صريحة ولا تُرسم صفرًا | 
| الأبعاد الثلاثية | معطَّلة افتراضيًا | 
| ألوان لها دلالة ثقافية معاكسة | تلميح (مثل الأحمر للسيئ والأخضر للجيد) | 

### 17.6 اللوحات (Dashboards)

* **تخطيط شبكي بالسحب:** بلاطات (رسم، KPI، جدول، نص، صورة)، وصفحات متعددة، وترويسة بشعار الجهة.

* **فلاتر عامة وتصفية متقاطعة:** تضغط شريحة فتُصفّى بقية الرسوم.

* **تحديث تلقائي:** ترتبط اللوحة بوصفة ومجلد مراقَب (F1)، فتتجدد بالملف الجديد وحدها.

* **المشاركة:** رابط مشفّر (D9)، وPDF للطباعة بفواصل صفحات (عبر `Typst`)، وصورة PNG، وإرسال مجدول (D8).

* **الإتاحة:** نص بديل تلقائي لكل رسم يصف الاتجاه الرئيسي، وعرض «كجدول» لأي رسم، وتنقل بلوحة المفاتيح بين النقاط، ودعم قارئ الشاشة.

### 17.7 التقنية

* **مواصفة الرسم (`chart spec`):** مخطط JSON بإصدار (`schema_version`) يصف مرجع البيانات والتشفير البصري والأنماط. حتمي: نفس المواصفة ونفس البيانات تعطيان نفس الصورة. مستوحى من لغات «قواعد الرسوم» مثل Vega-Lite لكن بمخطط خاص يدعم RTL والتقاويم، مع مكتبة **Graphify** لرسم المخططات الشبكية والعلاقات وشجرة النسب.

* **الرسم:** SVG للرسوم الصغيرة والتصدير النظيف، وCanvas للكثيفة (فوق نحو $5$ آلاف نقطة) مع تقليل النقاط (`downsampling`) بخوارزمية مثل LTTB مع الحفاظ على شكل البيانات، والتجميع قبل الرسم للملايين.

* **الحركة:** الخط يُرسم من بدايته والأعمدة تنمو (بواسطة GSAP)، بمدد القسم 6.4، وتُلغى عند «تقليل الحركة» وفي الطباعة.

* **التصدير:** SVG وPNG وPDF بجودة عالية، ورسم Excel أصلي قابل للتعديل (عبر `rust_xlsxwriter`) للأنواع التي يدعمها Excel، وبيانات الرسم CSV، ومواصفة JSON لإعادة الاستخدام.

* **الاختبار:** لقطات ذهبية لكل نوع $\times$ ثيمة $\times$ اتجاه $\times$ لغة، واختبار حتمية المواصفة، واختبارات إتاحة وتباين، وأداء (مليون صف مجمّعة في ثوانٍ وحركة $60$ إطارًا).
