# STUDIO-Phase-3 — Quad-Studio & Custom Free-Form Builder

**الحالة:** لم يبدأ؛ يعتمد على اجتياز [Phase 2](STUDIO-Phase-2.md).

## المتطلبات

- **LiveCleanSheetView:** تحرير خلايا عبر DataGraph، إضافة/حذف أعمدة وفق الصلاحيات، أعمدة محسوبة ومعادلات وتنظيف وفرز وترشيح وبحث، virtualization/pagination، حالة الخلية والتعديلات والأصل وأخطاء الأنواع، Undo/Redo.
- **CodeMotionDashboardView:** canvas وتصفية متبادلة وفلاتر تفاعلية وdrill-down وتجميع وفرز ومحرر رسوم. إعداد النوع وX/Y وSUM/AVG/COUNT/MIN/MAX والتجميع والفلاتر والترتيب والعناوين والتسميات والمفتاح والألوان. Rust يتحقق من الإعداد ويحسب البيانات؛ لا بيانات تجريبية في المخرج.
- **LiveKeynoteSlidesView:** إضافة وحذف وتكرار وترتيب شرائح، عناوين ونصوص وقوائم ورسوم وصور وVerifiedNumberChip، قوالب ومعاينة وحفظ وتنقل وعرض fullscreen. المرجع العددي لا يصبح نصًا ثابتًا إلا بفصل صريح من المستخدم.
- **SmartVerifiedDocView:** محرر Blocks مستقر: عناوين وفقرات وقوائم وجداول وصور ورسوم ومقاييس ومراجع ديناميكية، ترتيب وتنسيق وبحث واستبدال وUndo/Redo وRTL/LTR. ليس `contentEditable` وحده.
- **Free-Form:** إضافة وحذف وتحريك وتغيير حجم وترتيب طبقات وخصائص نصوص وصور ورسوم ومقاييس، وحفظ التخطيط. بديل بالنقر/لوحة المفاتيح لكل سحب.
- **Persistence:** حفظ الأصل والنسخة الحالية والتحويلات والأعمدة المحسوبة والمقاييس والرسوم والشرائح والمستند والتخطيطات والقالب والسيناريوهات والإعدادات. استعادة فعلية بعد إغلاق الصفحة، مع بقاء روابط البيانات.
- لا يحتاج البناء اليدوي AI أو قالبًا جاهزًا. الحفاظ على اللغتين والثيمين والإتاحة وتقليل الحركة.

## القبول

1. تعديل الجدول يحدث Dashboard والشرائح والتقرير، وتؤثر الفلاتر في كل مخرج مرتبط.
2. رسم مخصص ينتج نتائج Rust الصحيحة ويظل قابلًا للتحرير والحفظ والتحديث.
3. إنشاء/تعديل/حذف شرائح ومستند، وإدراج مؤشر موثق، وحفظ وإعادة فتح دون فقد مراجع.
4. Undo/Redo لجميع أنواع التحرير المعتمدة يحفظ الأصل ولا يفسد التخطيط.
5. بناء مشروع يدويًا بلا AI وبلا قالب، ثم استئناف التحرير بعد إعادة التشغيل.
6. نجاح اختبار انقطاع كتابة/حصة تخزين واستعادة آخر نسخة سليمة.
7. لا الانتقال إلى Phase 4 قبل جميع الشروط.
