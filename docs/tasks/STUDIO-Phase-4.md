# STUDIO-Phase-4 — Living Templates & Zero-License Export

**الحالة:** لم يبدأ؛ يعتمد على اجتياز [Phase 3](STUDIO-Phase-3.md).

## القوالب المطلوبة

1. `boardroom-keynote`: الافتراضي؛ ملخص تنفيذي ومؤشرات ورسوم وتوصيات ومخاطر.
2. `velocity-radar`: اتجاهات ومقارنات ونمو وتوزيع ومؤشرات مبيعات.
3. `impact-atlas`: خرائط عند وجود إحداثيات صالحة، وتوزيع وتغطية ومؤشرات تشغيل وأثر.
4. `forensic-xray`: الجودة والشذوذ والتناقضات وسجل التنظيف ومصدر المؤشرات.
5. `time-machine`: تحليل زمني وفترات وسيناريوهات واتجاهات، وتوقعات مميزة عن البيانات الفعلية.

كل قالب عناصر حية قابلة للتعديل والإضافة والحذف والترتيب وتغيير الألوان والخطوط وحفظ نسخة مخصصة. تغيير القالب لا يمس الأصل أو يفسد مراجع المقاييس.

## الكبسولة

- ملف مستقل `.safi.html` عبر زر مترجم؛ النص العربي «تصدير كبسولة تفاعلية شاملة (.safi.html)».
- يحتوي Dashboard وSlides وExecutive Report وفلاتر ورسوم وقيم المقاييس والتحقق وBLAKE3 وبيانات المشروع الوصفية.
- يعمل بلا شبكة أو API/Backend/CDN أو خطوط ومكتبات محملة وقت التشغيل؛ كل الموارد اللازمة مضمّنة.
- بيانات Snapshot بتاريخ وإصدار معلومين، مطابقة للمشروع عند التصدير، مع توضيح أن تعديلات الكبسولة لا تعود تلقائيًا إلى Safi.
- لا حسابات أو أسرار أو session tokens. لا تشغيل HTML/JavaScript من الخلايا أو النصوص أو الصور غير الموثوقة.
- تحقق من الحجم والإصدار والمراجع والموارد، ولا إدراج بيانات خاصة غير لازمة. البصمة ليست شهادة لصحة المصدر.

## القبول

- القوالب الخمسة قابلة للاستخدام والتخصيص والحفظ دون فقد مراجع.
- HTML صالح يفتح في متصفح حديث بلا أخطاء حرجة.
- فصل الشبكة بالكامل ثم تجربة الفلاتر والتنقل والرسوم؛ لا طلب خارجي أو اعتماد مخفي.
- تطابق الأرقام مع المشروع واحتفاظها بمراجع التحقق.
- فحص آلي لغياب الأسرار، واختبار نصوص خبيثة محلية يثبت عدم تنفيذها.
- لا الانتقال إلى Phase 5 قبل اجتياز الجميع.
