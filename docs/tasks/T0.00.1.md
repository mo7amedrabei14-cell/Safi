# المهمة `T0.00.1` — إزالة قفزة وتهنيج الانترو

## المشكلة المثبتة

عند التحميل البارد كانت ستارة HTML مختلفة عن إطار React الأول: قفزة رأسية 98.5px، وانتقال التقدم من نحو 65% إلى صفر، واستبدال الأعمدة بالنقاط. وبعد توحيد الإطار أكد المالك أن بداية الانترو ما زالت تبدو كتهنيج، وأن الانتقال إلى الموقع يحتاج حركة.

## سبب السكون والقطع

- انتظار الخطوط قبل بدء أي حركة، ثم توقف إجباري لمدة ثانية كاملة.
- بدء تحميل `ApplicationShell` بعد انتهاء الحركة فقط.
- إزالة الانترو مباشرة عند جاهزية التطبيق دون إطار خروج.

## النطاق

- توحيد الإطار الافتتاحي وأبعاده بين الستارة الثابتة و`SafiIntroSplash` من مصدر CSS واحد.
- بدء حركة الشعار والتقدم فور تركيب React، وتحميل الخطوط بالتوازي دون حجب الحركة.
- إلغاء ثانية التوقف الإجبارية.
- تحميل حزمة الصفحة مسبقًا أثناء الانترو دون تركيبها أو تشغيل مؤثراتها قبل اكتمال الحركة.
- إبقاء الانترو فوق صفحة جاهزة أثناء انتقال خروج قصير ومتصل، ثم إزالته بعد اكتمال الانتقال.
- إضافة اختبار Chromium للتسليمين: HTML إلى React، والانترو إلى الموقع.
- مراجعة مسار سطح المكتب الذي يستخدم حزمة الويب نفسها.

## خارج النطاق

- تغيير الهوية أو ترتيب تجميع الشعار.
- تعديل وظائف الاستوديوهات أو إنشاء انترو مستقل لسطح المكتب.

## قبول العمل

1. لا فرق هندسي بين آخر إطار HTML وأول إطار React، وتبدأ حركة React دون ثانية توقف.
2. لا يُركّب التطبيق ولا تعمل مؤثراته قبل اكتمال حركة الانترو، لكن حزمته تكون محملة قدر الإمكان.
3. يظهر التطبيق تحت الانترو أثناء خروج تدريجي مدته نحو 650ms، ولا يُحذف الانترو قبل اكتماله.
4. يحترم `prefers-reduced-motion` ويصل إلى الموقع دون حركات غير ضرورية.
5. لا أخطاء متصفح ولا انتكاس في اكتمال الشريط أو النصوص أو زر الدخول.
6. تنجح اختبارات الويب والبناء واختبار Chromium للتحميل البارد.
